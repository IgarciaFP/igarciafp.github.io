Registro de la sesión

    Actividad: Validación de email.

    El siguiente código genera un formulario de entrada de email. Tu misión consiste en comprobar que la dirección introducida es válida y que termina en @g.educaand.es.

    1. Comprueba el correo cuando el usuario pulse el botón «Aceptar» o la tecla Intro.
    2. Aplica al campo la clase correcto si el correo es válido y pertenece al dominio del centro, o la clase error en cualquier otro caso.
    3. Si el campo tiene la clase correcto, muestra el mensaje «Correo válido».
    4. Si el campo tiene la clase error, muestra el mensaje «Revisa tu correo del centro».
    5. El atributo novalidate desactiva la validación automática del navegador al enviar el formulario. Desde JavaScript, cancela el envío por defecto para que la página permanezca abierta y se pueda leer el mensaje.

    Pista para comprobar el dominio. Si has guardado el campo #correo en la variable valorintroducido, puedes usar esta expresión:

    valorintroducido.value.trim().toLowerCase().endsWith('@g.educaand.es');

    trim() elimina los espacios de los extremos y toLowerCase() convierte el texto a minúsculas. Después, endsWith() devuelve true si el texto termina en el dominio del centro. Comprueba también el formato del correo: @g.educaand.es cumple esa condición aunque le falte el nombre antes de la arroba.
