Registro de la sesión

    Actividad: Validación de una edad.

    El siguiente código genera un formulario de entrada de edad. Tu misión consiste en comprobar que el campo contiene un número entero entre 1 y 120, ambos incluidos. El campo vacío no es válido.

    1. Comprueba la edad al pulsar el botón «Aceptar» o Intro (Hay que controlar ambos casos).
    2. Aplica al campo la clase correcto si la edad es válida, o la clase error en cualquier otro caso.
    3. Si el campo tiene la clase correcto, muestra el mensaje «Edad válida».
    4. Si el campo tiene la clase error, muestra el mensaje «Revisa la edad introducida».
    5. El atributo novalidate desactiva la validación automática del navegador al enviar el formulario. Desde JavaScript, cancela el envío por defecto para que la página permanezca abierta y se pueda leer el mensaje.
