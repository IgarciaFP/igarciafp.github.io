01Trabajo del alumno

Texto · HTML · CSS · JS

La detección prepara todos los tipos. Selecciona cuáles analizar; por defecto no se analiza ninguno. Puedes indicar el tipo de entrada si la detección es ambigua.

Ortografía y gramática · revisión siempre activa

Al pulsar «Analizar entrega», se prepararán el texto y los comentarios seleccionados y se enviarán solo las palabras elegibles a LanguageTool. Requiere conexión. El código ejecutable no se envía.

Comprobación completada sin faltas: +50 puntos. Comprobación no realizada o fallida: 0 puntos. Cada falta aceptada reduce el índice inicial un 10 %, hasta un máximo del 100 %. Solo cuentan palabras originales de más de 4 letras cuya sugerencia cambie, añada o quite un único carácter (longitud ±1). Si no quedan palabras analizables o si falla el servicio, se muestra el motivo y no se aplica reducción.

Consultar glosario técnico. Siempre se excluyen términos técnicos de JavaScript, HTML, CSS y SSII (U01/U02), y palabras camelCase o PascalCase. El glosario solo contiene términos de más de cuatro letras. Esta opción añade un glosario inglés ampliable; no identifica todo el inglés y no se aplica si eliges inglés como idioma. Antes de enviar se retiran palabras de menos de cinco letras, términos del glosario, camelCase y tokens con puntos internos (nombre.js). Las reglas de formato usan el original.

LanguageTool · API pública para pruebas manuales; para producción automatizada utiliza una instancia propia o contratada.

Configurar pesos y umbral de entrevista

Se suman los pesos activados hasta un máximo de 100. Cada regla suma una sola vez. Un peso de 0 anula su contribución.

Longitud similar: al menos 3 comentarios; basta que el 95 % esté dentro de ±25 % de la media con la tolerancia inicial. Las reglas universales exigen un 95 % de coincidencia. Espaciado uniforme: misma separación antes de al menos el 80 % de los comentarios evaluables (mínimo 3).

El índice organiza la revisión docente. No es una probabilidad calibrada de uso de IA ni el porcentaje de código generado.
