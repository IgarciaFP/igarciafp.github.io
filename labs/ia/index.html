01Trabajo del alumno

Texto · HTML · CSS · JS

La detección prepara todos los tipos. Selecciona cuáles analizar; por defecto no se analiza ninguno. Puedes indicar el tipo de entrada si la detección es ambigua.

Ortografía y gramática · revisión siempre activa

Al pulsar «Analizar entrega», se enviarán el texto seleccionado y la prosa de los comentarios del código seleccionado a LanguageTool. Requiere conexión. El código ejecutable no se envía.

Sin faltas detectadas: +50 puntos. Cada falta aceptada reduce el índice inicial un 10 %, hasta un máximo del 100 %. Solo cuentan palabras originales de más de 4 letras cuya sugerencia cambie, añada o quite un único carácter (longitud ±1). Sin comentarios o si falla el servicio, se muestra el motivo y no se aplica reducción.

Se excluyen términos técnicos ingleses de un glosario ampliable; no identifica todas las palabras inglesas. La exclusión no se aplica si eliges inglés como idioma de revisión. Los términos siguen formando parte del texto enviado a LanguageTool.

LanguageTool · API pública para pruebas manuales; para producción automatizada utiliza una instancia propia o contratada.

Contenido separado por tipo

Fragmentos conservados en memoria durante esta sesión. El JSON del análisis incluye la preparación y el original. Para mezclar prosa y código, delimita el código con bloques Markdown (texto, html, css o javascript). El texto dentro de las etiquetas HTML pertenece a HTML.

Configurar pesos y umbral de entrevista

Se suman los pesos activados hasta un máximo de 100. Cada regla suma una sola vez. Un peso de 0 anula su contribución.

Longitud similar: al menos 3 comentarios; basta que el 95 % esté dentro de ±25 % de la media con la tolerancia inicial. Las reglas universales exigen un 95 % de coincidencia. Espaciado uniforme: misma separación antes de al menos el 80 % de los comentarios evaluables (mínimo 3).

El índice organiza la revisión docente. No es una probabilidad calibrada de uso de IA ni el porcentaje de código generado.
