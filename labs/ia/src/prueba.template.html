01Trabajo del alumno

Texto · HTML · CSS · JS

La detección prepara todos los tipos. Si no seleccionas tipos, se analizan todos los bloques no vacíos detectados. Los tipos solicitados vacíos se ignoran; si ninguno tiene datos, se analiza TXT. Puedes indicar el tipo de entrada si la detección es ambigua.

Ortografía y gramática · revisión siempre activa

Al pulsar «Analizar entrega», se prepararán el texto y los comentarios seleccionados y se enviarán solo las palabras elegibles a LanguageTool. Requiere conexión. El código ejecutable no se envía.

Comprobación completada sin faltas: +25 puntos. Comprobación no realizada o fallida: 0 puntos. El descuento es proporcional: faltas distintas ÷ líneas de texto/comentarios revisadas × 500, con un máximo del 100 %. Las líneas vacías, el código y las líneas sin palabras elegibles no cuentan. Cuentan las tildes omitidas en vocales minúsculas de palabras de tres letras o más, las frases que empiezan en minúscula, la falta de espacio tras puntuación y los signos de apertura ¿/¡ ausentes, cuando la API propone esa corrección. También cuentan coincidencias literales de: «de que», «hubieron», «han habido», «habían», «sobretodo», «mi», «tu», «a parte», «aun», «ni si quiera», «a ver» y «preveer». Son expresiones vigiladas, que pueden ser correctas según el contexto; «mi» y «tu» se revisan aunque tengan dos letras. Cada error o expresión repetida cuenta una vez; se excluyen los avisos de la API que contengan «Si es». Se ignoran las tildes omitidas en vocales mayúsculas y los demás errores. Si no quedan palabras analizables, no se solicita revisión. Si falla la API, solo pueden contar expresiones vigiladas detectadas localmente; no se asignan puntos por ausencia de faltas.

Consultar glosario técnico. Siempre se excluyen términos técnicos de JavaScript, HTML, CSS y SSII (U01/U02), y palabras camelCase o PascalCase. El glosario solo contiene términos de más de cuatro letras. Esta opción añade un glosario inglés ampliable; no identifica todo el inglés y no se aplica si eliges inglés como idioma. Antes de enviar se retiran términos del glosario, camelCase y tokens con puntos internos (nombre.js). Se conservan las palabras cortas. Las reglas de formato usan el original.

LanguageTool · API pública para pruebas manuales; para producción automatizada utiliza una instancia propia o contratada.

Configurar pesos y umbral de entrevista

Se suman los pesos activados hasta un máximo de 100. Cada regla suma una sola vez. Un peso de 0 anula su contribución.

Longitud similar: al menos 3 comentarios; basta que el 95 % esté dentro de ±25 % de la media con la tolerancia inicial. Las reglas universales exigen un 95 % de coincidencia. Espaciado uniforme: misma separación antes de al menos el 80 % de los comentarios evaluables (mínimo 3).

El índice organiza la revisión docente. No es una probabilidad calibrada de uso de IA ni el porcentaje de código generado.
