P01.01 · Visual Studio Code

Emmet:
HTML a toda velocidad

Escribe abreviaturas pequeñas y deja que VS Code construya las etiquetas. Antes se llamaba Zen Coding. Hoy lo conocemos como Emmet.

Meta: crear una miniweb con HTML y CSS usando Emmet, sin instalar extensiones. Tiempo aproximado: 45 minutos + reto final de 10 minutos.
🧭
Antes de empezar. Abre una carpeta en VS Code y crea reto-emmet.html. Mira abajo a la derecha: debe decir HTML. Si no, pulsa allí y elige “HTML”.
⌨️
Cómo expandir. Escribe la abreviatura sin espacios y selecciónala en las sugerencias. Pulsa Tab o Enter. Si no funciona: F1 → escribe Emmet: Expand Abbreviation → Enter.
Tu progreso0 de 10 misiones

Mapa secreto de Emmet

> entra dentro
+ coloca al lado
*3 repite 3 veces
.caja añade una clase
#inicio añade un id
{Hola} escribe texto

10 misiones rápidas

El esqueleto mágico

Aprende la abreviatura que inicia cualquier página.

⏱ 3 min

En la primera línea de reto-emmet.html, expande:

!

Cambia lang="en" por lang="es" y el título por Mi reto Emmet.

👀 ¿Qué debe aparecer?
<!doctype html>
<html lang="es">
  <head>...</head>
  <body>...</body>
</html>

Padres e hijos

El símbolo > mete una etiqueta dentro de otra.

⏱ 3 min

Dentro de <body>, expande:

nav>ul>li
✅ Resultado esperado
<nav>
  <ul>
    <li></li>
  </ul>
</nav>

Hermanos en fila

El signo + crea elementos al mismo nivel.

⏱ 3 min

Debajo del menú, expande:

header+main+footer

Comprueba la sangría: las tres etiquetas deben empezar a la misma altura.

La fotocopiadora

* repite una etiqueta.

⏱ 3 min

Borra el li vacío de la misión 2 y, dentro de ul, expande:

li*4

Cuenta el resultado. Debes tener exactamente cuatro <li>.

Clases e identificadores

. crea una clase y # un identificador único.

⏱ 4 min

Dentro de main, expande:

section#galeria.tarjetas
✅ Resultado esperado
<section id="galeria" class="tarjetas"></section>

Texto instantáneo

Las llaves {} guardan el texto.

⏱ 3 min

Dentro de header, expande:

h1{Mi planeta web}+p{Creado con Emmet}

Guarda con Ctrl + S.

Números automáticos

$ se convierte en 1, 2, 3…

⏱ 4 min

Dentro de section#galeria, expande:

article.tarjeta$*3>h2{Tarjeta $}

Busca tarjeta1, tarjeta2 y tarjeta3.

Atributos a medida

Los corchetes [] añaden información a una etiqueta.

⏱ 4 min

Dentro de cada tarjeta, prueba una vez:

a[href="#galeria" title="Volver"]{Subir}

Localiza los atributos href y title.

Grupos con paréntesis

Los paréntesis mantienen un bloque unido.

⏱ 4 min

Al final de main, expande:

(section>h2{Noticias}+p{Próximamente})+aside{Ayuda}

Observa: section y aside son hermanos; h2 y p están dentro de section.

Emmet también conoce CSS

Las propiedades CSS también tienen atajos.

⏱ 5 min

En <head> crea <style>. Dentro de body { }, escribe y expande cada abreviatura:

m20
p20
bgc#eef6ff
✅ Resultado esperado
body {
  margin: 20px;
  padding: 20px;
  background-color: #eef6ff;
}
⚡ RETO FINAL · 10 MINUTOS

Construye “La base secreta”

Crea un archivo nuevo llamado base-secreta.html. Solo puedes escribir a mano las abreviaturas, los cambios de texto y el CSS. Emmet debe crear las etiquetas.

  1. Expande ! y prepara el documento en español.
  2. Dentro de body, expande esta única superabreviatura:
div.web>(header>h1{Base secreta})+(main>section.tarjetas>article.tarjeta*3>h2{Misión $}+p{Pendiente})+(footer>p{Creado con Emmet})

Después crea un bloque <style> y usa al menos tres abreviaturas CSS de la misión 10. Cambia “Pendiente” por tres estados diferentes.

  • Documento HTML completo
  • Tres tarjetas numeradas
  • Cabecera, contenido y pie
  • Al menos tres reglas CSS
  • Sin errores rojos en VS Code
  • Se abre correctamente en Chrome
🛟 Pista si te bloqueas

Lee la abreviatura por trozos: web contiene tres grupos hermanos; el grupo central contiene tres artículos; cada artículo contiene un título y un párrafo.
