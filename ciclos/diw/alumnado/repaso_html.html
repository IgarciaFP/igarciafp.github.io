Punto de partida

Qué vas a demostrar

El objetivo no es memorizar una lista de etiquetas, sino elegir la etiqueta adecuada para cada contenido y producir un documento que el navegador, los buscadores y las tecnologías de apoyo puedan interpretar.

1

Estructurar

Crear un documento válido con head, metadatos y una jerarquía de títulos coherente.

2

Dar significado

Usar header, nav, main, section, article y footer.

3

Hacerlo accesible

Escribir alternativas para imágenes, asociar etiquetas a campos y escoger enlaces o botones correctamente.

Regla de oro: HTML describe qué es cada contenido. CSS decide su aspecto y JavaScript añade comportamiento.

Consulta rápida

La caja de herramientas HTML5

Abre solo los bloques que necesites. Puedes volver a ellos mientras resuelves el taller.

1. Esqueleto mínimo del documento
  • <!doctype html> activa el modo estándar de HTML5.
  • lang="es" informa del idioma principal.
  • charset, viewport y title pertenecen a head.
<!doctype html> <html lang="es"> <head> <meta charset="utf-8"> <meta name="viewport" content="width=device-width, initial-scale=1"> <title>Título descriptivo</title> </head> <body> <!-- Contenido visible --> </body> </html>
2. Regiones semánticas

Una etiqueta semántica explica la función del contenido; un div solo agrupa.

<header>Cabecera de página o de una sección.
<nav>Bloque principal de navegación.
<main>Contenido principal y único del documento.
<section>Bloque temático, normalmente con título.
<article>Pieza independiente y reutilizable.
<aside>Contenido relacionado pero secundario.
<figure>Imagen, gráfico o código con posible leyenda.
<footer>Pie de página o de una sección.
3. Texto, enlaces e imágenes
  • Los títulos h1–h6 expresan niveles, no tamaños visuales.
  • Usa a para ir a otro lugar y button para ejecutar una acción.
  • El atributo alt comunica la función o información de una imagen. Si es decorativa, puede ser alt="".
  • figure y figcaption relacionan un recurso con su leyenda.
<figure> <img src="mapa.svg" alt="Mapa con las tres etapas de la ruta"> <figcaption>Recorrido recomendado.</figcaption> </figure>
4. Formularios que se entienden
  • Cada control necesita un label. Su for debe coincidir con el id del campo.
  • Elige el type apropiado: email, number, date…
  • required indica que el dato es obligatorio.
  • Un formulario se envía con un button type="submit".
<label for="correo">Correo electrónico</label> <input id="correo" name="correo" type="email" required> <button type="submit">Suscribirme</button>
5. Errores frecuentes
  • No uses saltos br para separar párrafos.
  • No sustituyas botones por div con eventos.
  • No escribas un alt como «imagen.jpg»; describe la información relevante.
  • No saltes niveles de título solo para conseguir un tamaño concreto.
  • No repitas un mismo id en varios elementos.
