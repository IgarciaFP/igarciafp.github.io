UD02. CSS y diseño responsive

De los selectores a la maquetación: construye interfaces legibles, flexibles y adaptables.

1. CSS Cascade Style Sheets

Al crear una página, HTML identifica el contenido y su estructura: un título, un párrafo, una lista o un enlace. El navegador ya les aplica una apariencia básica, pero necesitamos controlar cómo se muestran para construir nuestro diseño.

CSS permite definir esa presentación. Sus siglas significan Cascading Style Sheets (hojas de estilo en cascada). Con CSS elegimos colores, tipografías, tamaños, espacios y la distribución de los elementos.

Por ejemplo, HTML indica que un texto es un título mediante <h1>. CSS permite mostrarlo en azul, darle más tamaño y separarlo del párrafo siguiente. El contenido sigue siendo el mismo; cambia su presentación.

Separar ambas tareas facilita el trabajo:

  • Mantener la web: una hoja CSS compartida permite cambiar el aspecto de los títulos de todas las páginas desde un único archivo.
  • Conseguir coherencia: botones, menús y tarjetas pueden reutilizar los mismos estilos.
  • Adaptar el diseño: el mismo HTML puede mostrarse en una columna en el móvil y en varias en una pantalla grande.
  • Facilitar la lectura: podemos ajustar el contraste, el tamaño del texto y la separación entre elementos.

CSS aplica reglas a los elementos del HTML. Cuando varias reglas afectan al mismo elemento, el navegador necesita decidir cuáles usar. Por eso estudiaremos la cascada, la herencia y la especificidad. Primero veremos cómo incorporar esas reglas a una página.

¿Cuál es la primera hoja de estilo que se aplica a nuestro código HTML?

Incluso en una página HTML sin CSS propio, los títulos suelen verse más grandes que los párrafos y los enlaces aparecen subrayados. ¿De dónde salen esos estilos? Puedes descubrirlo si inspeccionas un título y buscas el origen de la regla que fija su tamaño.

Comprobar la explicación

El navegador incorpora una hoja de estilos predeterminada, llamada hoja de estilos del agente de usuario (user agent stylesheet). Esa es la base que da aspecto al HTML aunque no hayamos escrito CSS: márgenes, tamaños de títulos, marcadores de listas y otros estilos iniciales.

Las reglas del autor se combinan con esa base mediante la cascada. Hablar de «primera» sirve para reconocer el punto de partida, pero el resultado no se decide solo por el orden de carga: también intervienen el origen, la importancia y los demás criterios que estudiaremos.

1.1. Formas de incluir CSS

Para aplicar estilos a una página, el navegador necesita saber dónde están escritas las reglas CSS. Podemos guardarlas en un archivo independiente, incluirlas en la cabecera del HTML o escribirlas directamente en un elemento. Las tres formas funcionan, pero la elección influye en lo fácil que será mantener la web.

Cuando construimos un sitio con varias páginas, lo más práctico es utilizar una hoja de estilos externa. Escribimos las reglas en un archivo, como estilos.css, y lo enlazamos desde la cabecera de cada página mediante <link>:

<!-- Dentro de head, en el archivo HTML -->
<link rel="stylesheet" href="css/estilos.css">

El atributo href indica la ruta del archivo. En este caso, el navegador buscará estilos.css dentro de la carpeta css. En ese archivo escribimos únicamente CSS, sin etiquetas <style>:

/* Archivo css/estilos.css */
p { color: navy; }

Si varias páginas enlazan esa misma hoja, todas compartirán sus estilos. Para cambiar el color de sus párrafos bastará con modificar una regla. Esta será la forma habitual de trabajar en nuestras prácticas.

También podemos escribir CSS en el propio documento, dentro de una etiqueta <style> situada en <head>. Es una hoja de estilos interna: resulta cómoda para probar una idea o preparar un ejemplo en un solo archivo.

<style>
  p { color: navy; }
</style>

Estas reglas se aplican a esa página. Si copiamos el bloque en varios documentos, después tendremos que modificarlos uno a uno; por eso conviene pasar los estilos compartidos a una hoja externa.

La tercera posibilidad es el estilo en línea, escrito en el atributo style de una etiqueta. Aquí no indicamos un selector: las declaraciones afectan directamente a ese elemento.

<p style="color: navy;">Texto de ejemplo</p>

Aunque permite un cambio rápido, repetir atributos style mezcla la presentación con el contenido y dificulta mantener los estilos. Evítalo como forma habitual de maquetar: utiliza clases y reglas en una hoja externa. Sigue teniendo usos concretos, como ciertos correos HTML o valores que JavaScript cambia durante la interacción.

1.2. Cascada

Un mismo elemento puede recibir declaraciones de distintas reglas. La cascada es el proceso que resuelve esos conflictos y determina el valor que se aplica a cada propiedad. El navegador considera, entre otros factores, el origen de los estilos, su importancia, las capas de cascada y la especificidad de los selectores. Cuando las declaraciones empatan en los criterios anteriores, gana la que aparece después.

/* Ambas reglas tienen el mismo origen, importancia y especificidad. */
p { color: navy; }
p { color: teal; } /* Esta declaración aparece después y gana. */

En este ejemplo, los párrafos se muestran en color verde azulado. Escribir una regla al final no garantiza que siempre prevalezca: el orden de aparición resuelve el empate, pero no sustituye a los demás criterios de la cascada.

1.3. Herencia

La herencia permite que ciertas propiedades pasen de un elemento a sus descendientes cuando estos no tienen un valor propio que las sustituya. Propiedades como color y font-family se heredan por defecto; otras, como margin, padding y border, no.

<article class="noticia">
  <p>Este texto hereda el color y la fuente del artículo.</p>
</article>

.noticia {
  color: navy;
  font-family: sans-serif;
  border: 1px solid navy;
}

El párrafo hereda el color y la fuente, pero no recibe un borde propio. Si añadimos .noticia p { color: teal; }, el párrafo utiliza su declaración de color en lugar del valor heredado. La palabra clave inherit permite pedir explícitamente el valor del padre, incluso en propiedades que no se heredan por defecto.

1.4. Especificidad

La especificidad es el peso de un selector y ayuda a resolver qué declaración gana cuando corresponde comparar selectores dentro de la cascada. Se comparan tres grupos en este orden: identificadores; clases, atributos y pseudoclases; y tipos de elemento y pseudoelementos.

  • #aviso: un identificador → 1-0-0.
  • .destacado: una clase → 0-1-0.
  • p: un tipo de elemento → 0-0-1.
<p id="aviso" class="destacado">Información importante</p>

#aviso { color: navy; }      /* 1-0-0 */
.destacado { color: teal; }  /* 0-1-0 */
p { color: maroon; }        /* 0-0-1 */

Si estas reglas son declaraciones normales del autor en la misma capa, gana #aviso, aunque esté escrito antes. La comparación se hace por grupos, de izquierda a derecha: no se suman como si fueran un número decimal. El selector universal * y los combinadores, como >, no añaden especificidad. !important modifica la importancia de una declaración, no la especificidad de su selector.

Ampliación: valores globales de las propiedades

Además de los valores propios de cada propiedad, CSS ofrece palabras clave comunes para decidir de dónde debe proceder su valor. Nos permiten heredar el del padre, recuperar el valor inicial o dejar que intervengan otras reglas de la cascada.

Valores globales de CSS
ValorQué haceEjemplo
inheritToma el valor calculado de la misma propiedad en el elemento padre, incluso si esa propiedad no se hereda normalmente.border-color: inherit;
initialUsa el valor inicial definido por CSS para esa propiedad. No equivale a recuperar los estilos del navegador para una etiqueta concreta.display: initial; da el valor inicial inline, incluso en un div.
unsetActúa como inherit en las propiedades heredables y como initial en las demás.color: unset; hereda el color; margin: unset; recupera su valor inicial, cero.
revertDescarta el valor del origen actual para esa propiedad. En estilos del autor deja que se apliquen los estilos del usuario o del navegador, según la cascada.h2 { font-size: revert; } permite recuperar el tamaño que corresponda a un h2 sin las reglas del autor para esa propiedad.
revert-layerDescarta el valor de la capa de cascada actual para esa propiedad y permite resolverlo con las demás capas. Las capas se declaran con @layer; no son elementos ni capas visuales.color: revert-layer;

La diferencia clave: initial consulta el valor inicial de la propiedad; revert permite recuperar estilos de otros orígenes. Por eso no producen necesariamente el mismo resultado.

1.5. ¿Qué hace !important?

Da prioridad a una declaración frente a las declaraciones normales del mismo origen. Se escribe después del valor y no aumenta la especificidad.

<p id="aviso">Hola</p>

/* CSS */
#aviso { color: blue; }
p { color: red !important; }

El texto será rojo: la declaración importante vence a la normal, aunque esta use un selector con ID.

Cuando añadir !important no cambia el resultado

Para el mismo párrafo, prueba estos dos casos por separado, en la misma hoja y sin capas:

/* Antes: el texto es azul. */
#aviso { color: blue !important; }
p { color: red; }

/* Después: sigue siendo azul. */
#aviso { color: blue !important; }
p { color: red !important; }

En el segundo caso, ambas declaraciones son importantes. Gana #aviso por su mayor especificidad: 1-0-0 frente a 0-0-1 de p. Añadir !important no cambia esos valores, aunque la regla de p esté escrita después.

No abuses de él: dificulta cambiar los estilos después. Primero revisa los selectores y su orden. Resérvalo para excepciones justificadas.

1.6. Propiedades abreviadas (shorthands)

Una propiedad abreviada (shorthand) permite definir varias propiedades relacionadas en una sola declaración. Por ejemplo, con border puedes dibujar un borde en los cuatro lados de una caja.

/* Sin abreviar el grosor, el estilo y el color */
.caja {
  border-width: 2px;
  border-style: solid;
  border-color: blue;
}

/* Con la propiedad abreviada */
.caja {
  border: 2px solid blue;
}

Ambas reglas dibujan el mismo borde. Lee los valores de la segunda de izquierda a derecha. 2px indica el grosor, solid dibuja una línea continua y blue le da color azul. Si después solo quieres cambiar el color, basta con escribir border-color: red;.

2. Selectores CSS

Una regla CSS combina un selector y un bloque de declaraciones. El selector localiza elementos del documento; cada declaración asigna un valor a una propiedad. Enlaza una hoja externa desde <head> para reutilizar los estilos entre páginas.

<link rel="stylesheet" href="css/estilos.css">

/* estilos.css */
.tarjeta {
  color: #1e3a8a;
  padding: 1rem;
}

2.1. Selectores básicos

Un selector indica a qué elementos HTML se aplica una regla. Para empezar, podemos seleccionar por el nombre de la etiqueta, por una clase, por un identificador o por un atributo. El selector universal permite seleccionar cualquier elemento.

Selectores de atributo

Los corchetes permiten seleccionar por la presencia de un atributo o por su valor. Son útiles para distinguir campos de formulario y tipos de enlace.

/* Elementos que tienen el atributo required. */
[required] { border-left: 3px solid #b45309; }

/* Campos cuyo tipo es exactamente email. */
input[type="email"] { background-color: #eff6ff; }

/* Enlaces cuyo href empieza por https://. */
a[href^="https://"] { text-decoration: underline; }

/* Enlaces cuyo href termina en .pdf. */
a[href$=".pdf"] { font-weight: bold; }

/* Enlaces cuyo href contiene /recursos/. */
a[href*="/recursos/"] { color: #0f766e; }

= compara el valor completo; ^=, su comienzo; $=, su final; y *=, una parte del valor. Estos selectores comparan el atributo: [href$=".pdf"] no coincidirá con un enlace que termine en .pdf?descarga=1.

Los selectores avanzados se estudiarán más adelante, después del modelo de caja.

3. Cajas, medidas y aspecto visual

Una tarjeta de producto puede parecer correcta con un título corto y desbordarse al añadir una descripción. Para entender qué ocurre, primero veremos cómo el navegador coloca sus cajas. Después controlaremos sus medidas, sus espacios y su aspecto. Trabajaremos con contenido que pueda crecer.

3.1. Cómo se muestran los elementos

3.1.1. El flujo normal del documento

Si escribes dos párrafos seguidos, el segundo aparece debajo del primero. Si añades un enlace dentro de un párrafo, comparte sus líneas con el texto. Esta colocación inicial es el flujo normal. El navegador la calcula a partir del orden del HTML, del espacio disponible y del tipo de caja que genera cada elemento.

3.1.2. Bloque, en línea y en línea con dimensiones

display decide cómo participa una caja en esa distribución. Compara estos tres valores antes de intentar cambiar el tamaño de un elemento.

Comportamiento en el flujo normal
ValorDistribuciónDimensiones y separación
blockComienza en una nueva línea. Con ancho automático, normalmente aprovecha el espacio horizontal disponible.Admite ancho, alto, relleno, borde y márgenes. Un ancho menor no hace que el bloque siguiente se coloque automáticamente a su lado.
inlineParticipa en las líneas de texto y puede fragmentarse entre varias líneas.En elementos no reemplazados, como un span, width y height no fijan su tamaño. Los márgenes verticales no separan las líneas; relleno y borde verticales pueden sobresalir sin aumentar su altura.
inline-blockParticipa en una línea como una unidad, sin fragmentarse entre líneas.Admite dimensiones y márgenes verticales. Los espacios del HTML pueden dejar huecos entre cajas; vertical-align ajusta su alineación en la línea.
noneNo genera cajas para el elemento ni para sus descendientes; desaparecen de la distribución.No conserva su espacio. Sus dimensiones, relleno, borde y márgenes no ocupan sitio. El HTML permanece en el DOM.
<p>Antes <span class="pieza">Pan del día</span> después</p>
.pieza {
  display: inline-block;
  width: 160px;
  min-height: 48px;
  padding: 8px;
  border: 2px solid teal;
}

Con inline-block, la pieza conserva sus dimensiones y comparte línea con el texto. Al cambiar a block, empieza una caja de bloque. Con inline, el contenido determina su ancho y los valores de width y height no fijan el tamaño de ese span. Las imágenes tienen dimensiones propias aunque participen en una línea.

3.2. Unidades de medida

Un número como 16 no indica por sí solo una longitud. La unidad establece con qué se compara. En CSS se escribe pegada al número, como 16px o 1rem. Para elegirla, decide primero qué debería hacer que la medida cambiase.

3.2.1. Píxeles y porcentajes

El píxel CSS permite declarar una medida concreta, por ejemplo un borde de 2px. El zoom del navegador puede ampliar su representación. Un porcentaje depende de una referencia que cambia según la propiedad. En un bloque ordinario, width: 80% se calcula respecto al ancho de su bloque contenedor.

.tarjeta {
  width: 80%;
  border: 2px solid navy;
}

Si el ancho interior del contenedor pasa de 500 a 300 px, ese ancho declarado pasa de 400 a 240 px. El borde conserva sus 2 px. Para interpretar la anchura exterior completa, también habrá que contar el relleno y el modelo de caja.

3.2.2. Unidades relativas al texto

Medidas que acompañan al texto
UnidadReferenciaUso
remTamaño de fuente del elemento raíz, normalmente html.Una escala común de texto y espaciado.
emTamaño de fuente del propio elemento. En font-size, toma el del padre.Relleno que crece con el texto de un botón.
chAnchura de avance del carácter 0 de la fuente utilizada.Limitar aproximadamente la longitud de una línea.
.boton { font-size: 1rem; padding: .5em 1em; }
.articulo { max-width: 65ch; }

Con una fuente raíz de 16 px, el botón tiene letra de 16 px y rellenos de 8 y 16 px. Si su letra crece, sus rellenos en em crecen con ella. Un ancho de 65 ch es una referencia tipográfica aproximada, no un recuento exacto de letras.

3.2.3. Unidades relativas a la ventana

Para una portada que ocupe la pantalla, la referencia útil es la ventana. 1vw equivale al 1 % de su ancho y 1vh al 1 % de su altura de referencia. 3.3. El modelo de caja

3.3.1. Contenido, relleno, borde y margen

Una caja tiene cuatro zonas. El contenido ocupa el centro. El relleno, padding, lo separa del borde. El borde delimita la caja. El margen, margin, deja separación exterior. Aumentar el relleno aleja el texto del borde; aumentar el margen separa la caja de sus vecinas.

3.3.2. Cómo se calcula el tamaño

Con box-sizing: content-box, el ancho declarado mide el contenido. El relleno y el borde se añaden. Con border-box, quedan incluidos en ese ancho. Compara una caja de 280 px con 20 px de relleno y 2 px de borde a cada lado. El margen queda fuera de ambos cálculos.

3.4. Dimensiones y proporciones

3.4.1. Ancho, alto y uso de auto

Una tarjeta necesita un ancho que encaje en la columna y una altura que admita su descripción. width y height fijan esas dimensiones. El valor auto deja que el navegador las calcule según el contenido y el modo de distribución.

.tarjeta {
  width: 80%;
  height: auto;
}

En un bloque de texto en flujo normal, la altura automática crece al añadir líneas. Su ancho automático aprovecha normalmente el espacio disponible descontando márgenes, relleno y borde. Un alto del 100 % necesita una referencia de altura definida para comportarse como esperamos. Las imágenes tienen además una proporción propia que interviene en el cálculo.

3.4.3. Mantener proporciones con aspect-ratio

.marco {
  width: 100%;
  aspect-ratio: 16 / 9;
}

La relación expresa ancho dividido entre alto. Con un ancho de 320 px, la altura preferida es de 180 px. Deja al menos una dimensión automática para que pueda calcularse. El contenido y los límites mínimos o máximos pueden modificar el resultado.

3.4.4. Ajustar el tamaño al contenido

Una etiqueta corta puede ocupar solo lo que necesita. min-content busca el tamaño mínimo usando los saltos disponibles; max-content mide el contenido sin saltos opcionales. fit-content se ajusta al espacio disponible entre esos límites.

.etiqueta { width: fit-content; }

Prueba con un nombre corto y con una palabra muy larga. Una palabra indivisible puede seguir sobresaliendo. El tamaño de la caja y la forma de partir su texto son decisiones diferentes que se completarán en Tipografía.

3.5.1. Relleno interior con padding

Si el texto queda pegado al borde de una tarjeta, añade relleno. Cada lado tiene su propiedad. Una longitud o un porcentaje no negativo determina cuánto separa el contenido del borde. En escritura horizontal, incluso los porcentajes del relleno superior e inferior se calculan respecto al ancho del bloque contenedor. padding permite establecer los cuatro lados de una vez.

3.5.3. Colapso de márgenes verticales

Dos bloques consecutivos no siempre suman sus márgenes verticales. Cuando esos márgenes colapsan, forman una sola separación. Si ambos son positivos, prevalece el mayor. Esto sucede en ciertas relaciones entre bloques del flujo normal; los márgenes de elementos Flexbox o Grid no colapsan entre sí.

También puede colapsar el margen superior del primer hijo con el del padre si no los separan borde, relleno o contenido en línea. Por eso un margen del hijo puede parecer que mueve al conjunto. Añadir un relleno al padre crea una separación interior real. Más adelante veremos cómo flow-root evita ese colapso sin añadir espacio. Los márgenes horizontales no colapsan.

3.5.4. Márgenes negativos

Un margen negativo reduce la separación y puede producir un solapamiento. Con dos márgenes verticales que colapsan, uno positivo de 24 px y otro negativo de −8 px, la separación resultante es 16 px.

.primero { margin-bottom: 24px; }
.segundo { margin-top: -8px; }

Si ambos márgenes que colapsan son negativos, se conserva el de mayor valor absoluto. Si el segundo del ejemplo pasa a −32 px, las cajas se solapan 8 px. Utiliza ese efecto cuando forme parte del diseño y comprueba que los textos sigan siendo legibles al crecer.

3.5.5. Espaciado según la dirección de escritura

El lado izquierdo es siempre el mismo borde físico. En cambio, el inicio de una línea depende de cómo se escribe. padding-inline-start añade relleno a la izquierda en español y a la derecha en árabe, con escritura horizontal. margin-block-end deja espacio después del bloque.

.aviso {
  padding-inline-start: 1rem;
  margin-block-end: 1.5rem;
}

Elige propiedades físicas si el diseño exige un lado concreto y propiedades lógicas si la separación debe acompañar a la lectura. Evita declarar ambas para el mismo lado sin tener claro cuál debe prevalecer.

3.8. Cuando el contenido no cabe

3.8.1. Desbordamiento horizontal y vertical

Una tabla ancha puede rebasar su contenedor y un aviso largo puede superar una altura limitada. A ese exceso se le llama desbordamiento. overflow-x controla el eje horizontal y overflow-y el vertical. Para decidir cómo tratarlo, comprueba primero qué dimensión está restringiendo el contenido.

3.8.2. Recortar o permitir desplazamiento

Valores de overflow
ValorResultado
visibleEl contenido puede salir de la caja. Es el valor inicial; puede solaparse con otros elementos.
hiddenRecorta el excedente sin ofrecer barras de desplazamiento. Puede existir desplazamiento programático.
clipRecorta y no crea un contenedor desplazable, ni siquiera mediante JavaScript.
scrollCrea un área desplazable y solicita barras incluso sin desbordamiento; su apariencia depende del sistema.
autoPermite desplazarse cuando el contenido lo necesita.
.panel {
  max-height: 15rem;
  overflow-y: auto;
}

El panel crece hasta su altura máxima y permite desplazarse cuando el contenido necesita más. hidden recorta sin ofrecer barras, mientras que clip impide además el desplazamiento programático. Cuando combines ejes, recuerda que un valor distinto de visible o clip hace que visible en el otro eje se calcule como auto, y clip como hidden.

3.8.4. Ocultar elementos

Ocultar un control plantea dos decisiones. Debes saber si conserva espacio y si la persona puede seguir alcanzándolo con el teclado. Compara las consecuencias antes de elegir una propiedad.

Curiosidad

Ocultar no siempre significa lo mismo
  • display: none elimina las cajas del elemento y sus descendientes del diseño y, normalmente, del árbol de accesibilidad. No conserva su espacio. El HTML permanece en el DOM.
  • visibility: hidden oculta el elemento conservando su espacio. El valor inicial es visible. En filas y columnas de tabla, collapse también permite retirar el espacio que ocupan.
  • opacity: 0 lo hace transparente, pero conserva su espacio y puede mantener clics y foco. No basta por sí solo para ocultar un control interactivo.

4. Posicionamiento y Centrado

Una descripción puede rodear una fotografía, una etiqueta puede ocupar la esquina de una tarjeta y un menú puede permanecer visible al desplazarnos. Para conseguirlo necesitamos saber qué ocurre con el espacio que ocupa cada elemento y cuál es su referencia de posición. Primero trabajaremos con los flotantes, después con position y finalmente aplicaremos estas ideas al centrado.

4.1. Elementos flotantes

4.1.1. Flotación con float y limpieza con clear

Para que una descripción rodee una foto de pan, aplica float a la imagen. La caja se sitúa a un lado y las líneas de texto disponibles se acortan para pasar junto a ella. Al terminar la altura de la foto, las líneas recuperan el ancho del contenedor.

<article class="noticia">
  <img src="hogaza.jpg" alt="Hogaza de centeno">
  <p>Hoy elaboramos una hogaza con fermentación lenta...</p>
  <p class="ingredientes">Ingredientes y alérgenos</p>
</article>
.noticia { background-color: #eff6ff; }
.noticia img {
  float: left;
  width: 8rem;
  margin-right: 1rem;
}

Necesitas una imagen disponible en esa ruta. left y right eligen el lado físico; inline-start e inline-end siguen la dirección de escritura. none desactiva la flotación. El texto debe tener suficiente longitud para observar cómo rodea la foto.

Si los ingredientes deben empezar debajo de la foto, aplica clear a ese bloque. El navegador lo desplaza hasta dejar atrás los flotantes del lado indicado.

.ingredientes { clear: both; }

left o right actúan sobre un lado; both deja atrás ambos. none permite el comportamiento habitual. Esta regla controla el comienzo del bloque siguiente dentro del mismo contexto de formato.

4.1.2. Contención de flotantes mediante flow-root

Acorta la descripción y retira el párrafo de ingredientes. El fondo de un bloque ordinario puede terminar antes que la foto porque su altura automática no incorpora por sí sola ese flotante. display: flow-root crea un contexto de formato de bloque, una región que organiza sus bloques y flotantes, y permite que el contenedor incluya los flotantes internos al calcular su altura.

.noticia {
  display: flow-root;
  background-color: #eff6ff;
}

La fotografía sigue flotando y el texto la sigue rodeando. También se evita que los márgenes de los hijos colapsen con los del padre, aunque aún pueden colapsar los de hermanos dentro de él.

Curiosidad

Cómo reconocer un clearfix en código existente

Antes de disponer de flow-root se añadió una caja final con clear para conseguir que el contenedor alcanzase la altura del flotante. El clearfix genera esa caja mediante un pseudoelemento, un concepto que desarrollaremos en Selectores avanzados.

.clearfix::after {
  content: "";
  display: table;
  clear: both;
}

Puedes encontrar esta solución en proyectos existentes. Para contener flotantes en un diseño nuevo, flow-root expresa directamente la necesidad.

4.2. Posicionamiento de elementos

position decide si una caja sigue su lugar en el flujo, se desplaza desde él o se coloca usando otra referencia. Observa tanto dónde aparece como qué sucede con el hueco que ocupaba.

Valores de position
Valor¿Conserva su espacio?Cómo se coloca

4.2.1. Posición relativa y absoluta

Con static, el elemento sigue el flujo normal y los desplazamientos no lo mueven. Con relative, puedes desplazar su dibujo manteniendo el hueco original para los demás elementos.

.aviso {
  position: relative;
  top: 8px;
  left: 12px;
}

Los lados top, right, bottom y left admiten auto, longitudes o porcentajes. En el ejemplo, el aviso baja 8 px y avanza 12 px respecto a su posición normal. Los porcentajes dependen de su bloque de referencia.

En cambio, una etiqueta de oferta puede ocupar la esquina de una ficha sin abrir un hueco entre sus párrafos. Con absolute, la etiqueta sale del flujo. Un antepasado con position: relative establece la referencia habitual para colocarla.

<article class="ficha">
  <span class="oferta">Oferta</span>
  <h2>Hogaza de centeno</h2>
  <p>Elaborada con masa madre.</p>
</article>

  position: absolute;
  top: .5rem;
  right: .5rem;
}

El relleno superior reserva sitio para que la etiqueta no tape el título. La etiqueta no aumenta la altura del padre. Si ningún antepasado establece su referencia, se usa el bloque inicial del documento.

4.2.2. Posición fija respecto al viewport

Un acceso de ayuda que deba seguir visible puede usar fixed. Sale del flujo y normalmente se coloca respecto al viewport, el área del navegador en la que se muestra la página. Por eso mantiene su posición al desplazar el documento.

.ayuda {
  position: fixed;
  right: 1rem;
  bottom: 1rem;
}

Comprueba que no cubra texto o controles, especialmente con zoom. Un antepasado transformado puede establecer otra referencia para fixed y absolute. Esa condición explica por qué un elemento fijo puede dejar de seguir la ventana en algunos componentes.

4.2.3. Posición adherente (sticky)

Una navegación puede comenzar en su lugar normal y permanecer visible al alcanzar el borde superior. sticky conserva su espacio y se adhiere dentro de los límites de su contenedor.

.menu {
  position: sticky;
  top: 0;
}

Necesita un umbral como top y espacio para desplazarse. Los antepasados con overflow auto, scroll o hidden pueden cambiar su zona de referencia. Usa contenido suficiente para comprobar dónde empieza y termina el efecto.

4.2.4. Contextos de apilamiento y orden visual (z-index)

Cuando dos cajas se solapan, z-index ayuda a decidir cuál se dibuja delante. Admite auto o un entero. En elementos posicionados, un entero puede crear un contexto de apilamiento, un grupo que se ordena como una unidad respecto a otros grupos.

.ficha { position: relative; z-index: 1; }
.menu { position: sticky; top: 0; z-index: 10; }

Un hijo de la ficha no puede saltar por encima del grupo de la navegación solo por recibir un número enorme. Primero se compara el nivel del grupo al que pertenece. Opacidad menor que uno o ciertas transformaciones también pueden crear contextos.

4.3. Técnicas de centrado

Para centrar, identifica qué se mueve y dentro de qué espacio. Un título, su tarjeta y una etiqueta superpuesta tienen referencias diferentes. La siguiente figura distingue esos resultados.

4.3.1. Centrado de contenido en línea

.titulo { text-align: center; }

La regla alinea las líneas dentro de la caja del título. También afecta al contenido en línea de ese contenedor. La propia caja mantiene la colocación que le corresponde en el flujo.

4.3.2. Centrado de cajas de bloque con márgenes automáticos

Para centrar un bloque, deja espacio libre a sus lados y permite que los márgenes laterales lo compartan.

.articulo {
  width: 92%;
  max-width: 65ch;
  margin-inline: auto;
}

5. Selectores avanzados

Podemos afinar la selección combinando condiciones y seleccionando elementos según su estado de interacción o su posición dentro del documento. El objetivo es expresar qué elementos necesitamos seleccionar sin añadir clases innecesarias ni crear reglas difíciles de mantener.

Agrupar selectores y combinar condiciones

La coma permite compartir declaraciones entre varios selectores. En cambio, escribir selectores juntos y sin espacio exige que un mismo elemento cumpla todas esas condiciones.

/* Selecciona todos los h1 y todos los h2. */
h1, h2 { color: #1e3a8a; }

/* Solo los párrafos que tengan la clase destacado. */
p.destacado { font-weight: bold; }

/* Elementos que tengan las dos clases. */
.tarjeta.destacado { border: 2px solid #0f766e; }

Fíjate en el espacio: p.destacado selecciona un párrafo con esa clase; p .destacado selecciona un elemento con esa clase que esté dentro de un párrafo. Esta segunda forma utiliza una relación de descendencia.

Agrupar con :is()

:is() selecciona los elementos que coincidan con cualquiera de los selectores entre paréntesis. Permite agrupar alternativas sin repetir la parte común.

/* Sin :is(): repetimos .tarjeta. */
.tarjeta h2,
.tarjeta h3 {
  color: #1e3a8a;
}

/* Con :is(): seleccionamos los mismos elementos. */
.tarjeta :is(h2, h3) {
  color: #1e3a8a;
}

Ambas reglas seleccionan los h2 y h3 que estén dentro de .tarjeta.

Especificidad: :is() toma la del selector más específico de su lista. Por ejemplo, :is(.aviso, #principal) aporta el peso de un ID, incluso cuando coincide por la clase. Evita mezclar IDs y clases sin necesitarlo.

5.1. Variables y cálculos en CSS

Imagina que el color de marca cambia o que una tarjeta debe caber tanto en un móvil como en un escritorio. Una variable permite nombrar una decisión de diseño y reutilizarla. Una función de cálculo permite obtener una medida a partir del espacio disponible.

Declarar, reutilizar y redefinir una variable

Las propiedades personalizadas evitan repetir colores, espacios y otros valores. Se declaran con --nombre y se utilizan mediante var(). Así puedes cambiar una decisión visual desde un único lugar.

:root {
  --color-marca: #6d28d9;
  --espacio: 1rem;
}

.tarjeta {
  border: 2px solid var(--color-marca);
  padding: var(--espacio);
  border-radius: var(--radio, .5rem);
}

.tarjeta--oferta {
  --color-marca: #9a3412;
}

:root establece valores generales. En una tarjeta con las clases tarjeta tarjeta--oferta, el borde será marrón porque se redefine --color-marca en ese elemento. Las propiedades declaradas con -- participan en la cascada y se heredan por defecto.

var(--radio, .5rem) usa .5rem si la variable no está definida o tiene un valor inválido como propiedad personalizada. No corrige cualquier error de tipo: si --radio: rojo, ese texto no sirve como radio y la declaración de border-radius será inválida.

Utiliza nombres por función, como --color-marca. var() sustituye valores, no nombres de propiedades ni selectores.

Calcular medidas y elegir límites

Cálculos con medidas
FunciónResultadoEjemplo
calc()Opera con medidas compatiblescalc(100% - 2rem)
min()Escoge el menor valormin(90%, 65ch)
max()Escoge el mayor valormax(1rem, 2vw)
clamp()Limita un valor entre mínimo y máximoclamp(1rem, 2vw, 2rem)

Con calc() puedes restar una longitud fija a un porcentaje que depende del contenedor. Deja espacios a ambos lados de + y -. Con min() y max() se comparan medidas compatibles. Por ejemplo, padding: max(1rem, 2vw) mantiene al menos 1 rem de relleno y permite que crezca en pantallas anchas.

  width: min(65ch, calc(100% - 2 * var(--margen-pagina)));
  margin-inline: auto;
}

  font-size: clamp(2rem, 1.5rem + 2vw, 3.5rem);
}

En un contenedor de 360 px, el cálculo deja 328 px para el artículo tras reservar 16 px por lado. min() escoge el menor entre esos 328 px y el límite de lectura de 65 ch. Para el título, clamp() intenta aplicar el valor central, que crece con la ventana, y lo mantiene entre 2 y 3,5 rem.

Ver cómo escribir las propiedades abreviadas

En el contenedor, flex-flow reúne dirección y salto de línea. En cada hijo, flex reúne crecimiento, reducción y tamaño base, en ese orden.

.galeria {
  display: flex;
  flex-flow: row wrap; /* flex-direction + flex-wrap */
  gap: 1rem 2rem;     /* row-gap + column-gap */

.tarjeta {
  flex: 1 1 15rem;
  /* flex-grow: 1; flex-shrink: 1; flex-basis: 15rem; */
}
  • flex: auto equivale a 1 1 auto: crece y se reduce desde su base automática.

  • flex: none equivale a 0 0 auto: no crece ni se reduce.
  • Los navegadores expanden flex: 1 a 1 1 0%. Para controlar la base sin ambigüedad, escribe los tres componentes.

gap acepta un valor para ambas separaciones o dos para filas y columnas. En Flexbox, qué separación queda entre líneas o entre elementos depende de flex-direction. No añade margen exterior.

place-content reúne align-content y justify-content: por ejemplo, place-content: center space-between. El primero necesita varias líneas y espacio transversal. Para alinear los elementos de Flexbox, utiliza align-items; justify-items no actúa en este modelo.

Abreviar las plantillas, la colocación y la alineación en Grid

Ver cómo escribir las propiedades abreviadas

grid-template reúne filas, columnas y áreas de la cuadrícula explícita. La barra separa filas y columnas:

.pagina {
  display: grid;
  grid-template: "cabecera cabecera" auto
                 "menu contenido" 1fr / 12rem 1fr;
  gap: 1rem 2rem; /* Filas | columnas */
}

grid también incluye las propiedades de creación automática. grid: auto 1fr / 12rem 1fr define dos filas y dos columnas, elimina las áreas nombradas y restablece las opciones implícitas omitidas. No restablece gap. Si quieres conservar la configuración automática, utiliza grid-template.

En esta cuadrícula, gap: 1rem 2rem equivale a row-gap: 1rem y column-gap: 2rem.

Para situar un elemento, grid-row y grid-column reúnen línea inicial y final con /. span expresa cuántas pistas abarca.

.destacada {
  grid-row: 1 / 3;
  grid-column: 2 / span 2;
}
/* Equivalente mediante cuatro límites: */
.destacada { grid-area: 1 / 2 / 3 / span 2; }
/* O un área previamente nombrada: */
main { grid-area: contenido; }

El orden de los cuatro límites de grid-area es fila inicial / columna inicial / fila final / columna final; no es el orden de los márgenes. Con un número solo en grid-row o grid-column, el final queda en auto; un nombre puede hacer referencia a un área.

Las abreviaturas de alineación escriben primero align-* y después justify-*. Con un único center se aplica a ambos ejes:

.rejilla {
  display: grid;
  place-items: start center; /* align-items + justify-items */
  place-content: center;    /* align-content + justify-content */
}
.elemento { place-self: end center; } /* align-self + justify-self */

place-items alinea los elementos en sus celdas; place-content distribuye la cuadrícula cuando sobra espacio; place-self ajusta un elemento concreto.

  grid-row-start: 1;
  grid-column-start: 2;
  grid-row-end: 3;
  grid-column-end: 5;
}

10.1. Adaptar un componente con consultas de contenedor

Una tarjeta puede aparecer en una columna estrecha o en una zona amplia de la misma página. ¿Debe tener el mismo aspecto en ambas? Las consultas de contenedor permiten adaptar sus estilos al espacio de su contenedor, no al ancho de la ventana.

Un elemento envolvente agrupa la tarjeta. Para consultar su tamaño, declara container-type: inline-size; en escritura horizontal permite consultar su ancho. container-name le asigna un nombre opcional para identificarlo en la consulta.

Shorthand

Ver cómo escribir las propiedades abreviadas

El nombre identifica el contenedor para las consultas; inline-size permite consultar su tamaño en el eje en línea. Si escribes solo container: ficha, el tipo vuelve a normal. No basta para crear un contenedor de consultas de tamaño.
