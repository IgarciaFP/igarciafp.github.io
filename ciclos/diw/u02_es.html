UD02. CSS y diseño responsive

De los selectores a la maquetación: construye interfaces legibles, flexibles y adaptables.

1. CSS Cascade Style Sheets

CSS (Cascading Style Sheets, hojas de estilo en cascada) es el lenguaje que define la presentación de un documento HTML: colores, tipografía, espacios y distribución de los elementos. Para entender cómo decide el navegador qué estilos aplicar, necesitamos distinguir tres conceptos: cascada, herencia y especificidad.

1.1. Cascada

Un mismo elemento puede recibir declaraciones de distintas reglas. La cascada es el proceso que resuelve esos conflictos y determina el valor que se aplica a cada propiedad. El navegador considera, entre otros factores, el origen de los estilos, su importancia, las capas de cascada y la especificidad de los selectores. Cuando las declaraciones empatan en los criterios anteriores, gana la que aparece después.

/* Ambas reglas tienen el mismo origen, importancia y especificidad. */
p { color: navy; }
p { color: teal; } /* Esta declaración aparece después y gana. */

En este ejemplo, los párrafos se muestran en color verde azulado. Escribir una regla al final no garantiza que siempre prevalezca: el orden de aparición resuelve el empate, pero no sustituye a los demás criterios de la cascada.

1.2. Herencia

La herencia permite que ciertas propiedades pasen de un elemento a sus descendientes cuando estos no tienen un valor propio que las sustituya. Propiedades como color y font-family se heredan por defecto; otras, como margin, padding y border, no.

<article class="noticia">
  <p>Este texto hereda el color y la fuente del artículo.</p>
</article>

.noticia {
  color: navy;
  font-family: sans-serif;
  border: 1px solid navy;
}

El párrafo hereda el color y la fuente, pero no recibe un borde propio. Si añadimos .noticia p { color: teal; }, el párrafo utiliza su declaración de color en lugar del valor heredado. La palabra clave inherit permite pedir explícitamente el valor del padre, incluso en propiedades que no se heredan por defecto.

1.3. Especifidad

La especificidad es el peso de un selector y ayuda a resolver qué declaración gana cuando corresponde comparar selectores dentro de la cascada. Se comparan tres grupos en este orden: identificadores; clases, atributos y pseudoclases; y tipos de elemento y pseudoelementos.

  • #aviso: un identificador → 1-0-0.
  • .destacado: una clase → 0-1-0.
  • p: un tipo de elemento → 0-0-1.
<p id="aviso" class="destacado">Información importante</p>

#aviso { color: navy; }      /* 1-0-0 */
.destacado { color: teal; }  /* 0-1-0 */
p { color: maroon; }        /* 0-0-1 */

Si estas reglas son declaraciones normales del autor en la misma capa, gana #aviso, aunque esté escrito antes. La comparación se hace por grupos, de izquierda a derecha: no se suman como si fueran un número decimal. El selector universal * y los combinadores, como >, no añaden especificidad. !important modifica la importancia de una declaración, no la especificidad de su selector.

Ampliación

¿Qué hace !important?

Da prioridad a una declaración frente a las declaraciones normales del mismo origen. Se escribe después del valor y no aumenta la especificidad.

<p id="aviso">Hola</p>

/* CSS */
#aviso { color: blue; }
p { color: red !important; }

El texto será rojo: la declaración importante vence a la normal, aunque esta use un selector con ID.

No abuses de él: dificulta cambiar los estilos después. Primero revisa los selectores y su orden. Resérvalo para excepciones justificadas.

2. Selectores CSS

Una regla CSS combina un selector y un bloque de declaraciones. El selector localiza elementos del documento; cada declaración asigna un valor a una propiedad. Enlaza una hoja externa desde <head> para reutilizar los estilos entre páginas.

<link rel="stylesheet" href="css/estilos.css">

/* estilos.css */
.tarjeta {
  color: #1e3a8a;
  padding: 1rem;
}

2.1. Selectores básicos

Un selector indica a qué elementos HTML se aplica una regla. Para empezar, podemos seleccionar por el nombre de la etiqueta, por una clase o por un identificador. El selector universal permite seleccionar cualquier elemento.

Selectores básicos y elementos seleccionados
SelectorEjemploQué selecciona
De tipo o etiquetapTodos los elementos <p>.
De clase.tarjetaLos elementos cuyo atributo class contiene la clase tarjeta.
De identificador#cabeceraEl elemento con id="cabecera". Ese identificador debe ser único en el documento.
Universal*Todos los elementos. No añade especificidad.
<header id="cabecera">Noticias del aula</header>
<p>Párrafo de introducción.</p>
<p class="destacado">Aviso importante.</p>
<article class="tarjeta destacado">Próximo taller</article>

/* CSS */
p { line-height: 1.6; }
.destacado { color: #0f766e; }
#cabecera { background-color: #eff6ff; }
* { box-sizing: border-box; }

En este ejemplo, .destacado selecciona tanto el segundo párrafo como el artículo. Una clase puede reutilizarse en varios elementos y un elemento puede tener varias clases, separadas por espacios en el HTML. Utiliza clases para estilos reutilizables y reserva los identificadores para elementos concretos.

Agrupar selectores y combinar condiciones

La coma permite compartir declaraciones entre varios selectores. En cambio, escribir selectores juntos y sin espacio exige que un mismo elemento cumpla todas esas condiciones.

/* Selecciona todos los h1 y todos los h2. */
h1, h2 { color: #1e3a8a; }

/* Solo los párrafos que tengan la clase destacado. */
p.destacado { font-weight: bold; }

/* Elementos que tengan las dos clases. */
.tarjeta.destacado { border: 2px solid #0f766e; }

Fíjate en el espacio: p.destacado selecciona un párrafo con esa clase; p .destacado selecciona un elemento con esa clase que esté dentro de un párrafo. Esta segunda forma utiliza una relación de descendencia.

2.2. Selectores avanzados

Podemos afinar la selección utilizando relaciones entre elementos, atributos, estados de interacción y posiciones dentro del documento. El objetivo es expresar qué elementos necesitamos seleccionar sin añadir clases innecesarias ni crear reglas difíciles de mantener.

Relaciones entre elementos: combinadores

Combinadores CSS
RelaciónEjemploQué selecciona
Descendiente: espacionav aLos enlaces que estén dentro de nav, aunque haya elementos intermedios.
Hijo directo: >nav > aSolo los enlaces cuyo padre sea nav.
Hermano siguiente: +h2 + pEl párrafo inmediatamente posterior a un h2, con el mismo padre.
Hermanos posteriores: ~h2 ~ pTodos los párrafos posteriores al h2 que compartan su padre.
<nav>
  <a href="inicio.html">Inicio</a>
  <div><a href="contacto.html">Contacto</a></div>
</nav>

nav a { color: #1e3a8a; }       /* Los dos enlaces. */
nav > a { font-weight: bold; } /* Solo Inicio. */

Los combinadores describen relaciones, pero no suman especificidad. Evita cadenas excesivamente largas que dependan de cada contenedor intermedio: un pequeño cambio en el HTML podría dejar la regla sin efecto.

Selectores de atributo

Los corchetes permiten seleccionar por la presencia de un atributo o por su valor. Son útiles para distinguir campos de formulario y tipos de enlace.

/* Elementos que tienen el atributo required. */
[required] { border-left: 3px solid #b45309; }

/* Campos cuyo tipo es exactamente email. */
input[type="email"] { background-color: #eff6ff; }

/* Enlaces cuyo href empieza por https://. */
a[href^="https://"] { text-decoration: underline; }

/* Enlaces cuyo href termina en .pdf. */
a[href$=".pdf"] { font-weight: bold; }

/* Enlaces cuyo href contiene /recursos/. */
a[href*="/recursos/"] { color: #0f766e; }

= compara el valor completo; ^=, su comienzo; $=, su final; y *=, una parte del valor. Estos selectores comparan el atributo: [href$=".pdf"] no coincidirá con un enlace que termine en .pdf?descarga=1.

Pseudoclases: estado y posición

Las pseudoclases se escriben con dos puntos. Seleccionan elementos que cumplen una condición, como estar bajo el puntero, tener foco visible o ocupar una posición determinada entre sus hermanos.

button:hover { background-color: #ccfbf1; }
button:focus-visible { outline: 3px solid #1e3a8a; }
input:checked { accent-color: #0f766e; }
button:disabled { opacity: .6; }

li:first-child { font-weight: bold; }
li:last-child { border-bottom: 0; }
li:nth-child(2n) { background-color: #eff6ff; }
li:not(.destacado) { color: #475569; }

:nth-child(2n) selecciona posiciones pares. Las posiciones empiezan en 1 y se cuentan entre todos los hermanos que sean elementos; la regla anterior solo se aplica si el elemento de esa posición es un li. :not(.destacado) excluye los elementos con esa clase.

No bases una interacción únicamente en :hover: quien utiliza teclado necesita un foco visible y una forma de activar los controles. Conserva el indicador de foco o sustitúyelo por otro claramente perceptible.

Pseudoelementos: partes de un elemento

Se escriben con dos puntos consecutivos (::) y permiten aplicar estilos a partes de un elemento o generar contenido decorativo. No equivalen a añadir elementos HTML reales.

.articulo::first-letter { font-size: 2em; }
.articulo::first-line { font-weight: bold; }
li::marker { color: #0f766e; }

.etiqueta::before {
  content: "";
  display: inline-block;
  width: .5em;
  height: .5em;
  margin-right: .4em;
  border-radius: 50%;
  background-color: #0f766e;
}

::before y ::after suelen necesitar content para generar su caja. Úsalos para detalles decorativos; escribe las instrucciones, etiquetas e información esencial en el HTML. Recuerda la diferencia: una pseudoclase selecciona según una condición; un pseudoelemento permite estilizar una parte.

3. Modelo de caja y flujo

Cada caja tiene contenido, relleno, borde y margen. El relleno separa el contenido del borde; el margen establece separación exterior. Los márgenes verticales de algunos bloques en flujo normal pueden colapsar, de modo que no siempre se suman.

3.1. Tamaño de la caja

La propiedad box-sizing determina qué partes de la caja quedan incluidas en el tamaño que declaramos con width y height. No cambia la estructura del modelo: contenido, relleno, borde y margen siguen existiendo.

  • content-box: el ancho y el alto declarados corresponden al contenido. El relleno y el borde se añaden por fuera. Es el valor inicial de la propiedad, aunque algunos elementos reciben otros estilos del navegador.
  • border-box: el tamaño declarado incluye contenido, relleno y borde. El espacio disponible para el contenido se reduce al añadir relleno y borde.

En ambos casos, el margen queda fuera. Para una caja de width: 280px, padding: 20px y border: 2px solid:

Cálculo del ancho sin contar márgenes
ModeloAncho del contenidoAncho hasta el borde exterior
content-box280 px280 + 40 + 4 = 324 px
border-box280 − 40 − 4 = 236 px280 px
.caja {
  width: 280px;
  padding: 20px;
  border: 2px solid #1e3a8a;
}
.caja--contenido { box-sizing: content-box; }
.caja--borde { box-sizing: border-box; }

/* Un criterio uniforme para la página y sus pseudoelementos. */
*, *::before, *::after { box-sizing: border-box; }

Prueba cada variante por separado y mide su ancho en el inspector. Con border-box, el contenido no puede tener un tamaño negativo: un relleno y un borde excesivos pueden superar el tamaño declarado.

Consulta: MDN · box-sizing.

3.2. Display: cómo participa una caja en el diseño

display controla cómo se comporta una caja respecto a las que la rodean y cómo distribuye a sus hijos. Estas dos decisiones son distintas: un contenedor puede participar como bloque y organizar su interior con Flexbox.

Bloque, en línea y bloque en línea

Comportamiento en el flujo normal
ValorDistribuciónDimensiones y separación
blockComienza en una nueva línea. Con ancho automático, normalmente aprovecha el espacio horizontal disponible.Admite ancho, alto, relleno, borde y márgenes. Un ancho menor no hace que el bloque siguiente se coloque automáticamente a su lado.
inlineParticipa en las líneas de texto y puede fragmentarse entre varias líneas.En elementos no reemplazados, como un span, width y height no fijan su tamaño. Los márgenes verticales no separan las líneas; relleno y borde verticales pueden sobresalir sin aumentar su altura.
inline-blockParticipa en una línea como una unidad, sin fragmentarse entre líneas.Admite dimensiones y márgenes verticales. Los espacios del HTML pueden dejar huecos entre cajas; vertical-align ajusta su alineación en la línea.
<div class="prueba">
  Antes <span class="pieza">Una caja</span> después
</div>

.pieza {
  display: inline-block; /* Prueba también inline y block. */
  width: 10rem;
  min-height: 3rem;
  padding: .5rem;
  border: 2px solid #0f766e;
  vertical-align: middle;
}

Con inline observa cómo el texto determina el ancho; con block, cómo aparecen saltos de línea; con inline-block, cómo se mantienen las dimensiones dentro de la línea. Las imágenes son elementos reemplazados: pueden tener ancho y alto aunque participen en línea.

Distribuir el interior: Flexbox, Grid y otros valores

  • flex organiza los hijos directos con Flexbox; grid, con Grid. El contenedor participa como bloque. Se desarrollan en sus apartados específicos.
  • inline-flex e inline-grid conservan esa distribución interior, pero el contenedor participa en línea.
  • flow-root crea un nuevo contexto de formato de bloque. Resulta útil para contener elementos flotantes y evitar que los márgenes de los hijos colapsen con los del contenedor.
  • list-item genera una caja de lista con marcador. table, table-row y table-cell permiten comportamientos de tabla; para datos tabulares, utiliza HTML de tabla semántico.
  • contents elimina la caja del elemento y deja participar a sus hijos. No lo uses como sustituto general de un contenedor: comprueba su efecto en la accesibilidad y en los estilos del propio elemento.

Ocultar no siempre significa lo mismo

  • display: none elimina las cajas del elemento y sus descendientes del diseño y, normalmente, del árbol de accesibilidad. El HTML permanece en el DOM.
  • visibility: hidden oculta el elemento conservando su espacio. No es equivalente a eliminarlo del flujo.
  • opacity: 0 lo hace transparente, pero conserva su espacio y puede mantener clics y foco. No basta por sí solo para ocultar un control interactivo.

Cambiar display modifica la presentación, no la semántica: convertir un div en inline-block no lo convierte en un botón. Usa siempre el elemento HTML adecuado.

Consulta: MDN · display.

3.3. Dimensiones, mínimos y máximos

Definir un tamaño exacto y establecer un límite son operaciones distintas. Una tarjeta puede crecer con su texto y tener una altura mínima; un artículo puede adaptarse al ancho de pantalla sin superar una anchura cómoda para leer.

Propiedades de dimensiones
PropiedadFunciónEjemplo
width / heightEstablecen ancho y alto, sujetos a los límites mínimo y máximo.width: 80%; height: auto;
min-width / min-heightFijan el mínimo permitido.min-height: 12rem;
max-width / max-heightFijan el máximo permitido. No eliminan el contenido que no cabe.max-width: 65ch;
inline-size / block-sizeEquivalentes lógicos según el modo de escritura; en escritura horizontal suelen corresponder a ancho y alto.inline-size: 100%;
min-inline-size, max-inline-size, min-block-size, max-block-sizeMínimos y máximos en los ejes lógicos.max-inline-size: 65ch;
aspect-ratioDefine una proporción preferida entre ancho y alto. Para determinar una dimensión a partir de ella, al menos una debe ser automática.aspect-ratio: 16 / 9;
/* Se adapta a la pantalla y limita el ancho de lectura. */
.articulo {
  width: calc(100% - 2rem);
  max-width: 65ch;
  margin-inline: auto;
}

/* Puede crecer cuando se añade texto. */
.tarjeta { min-height: 12rem; height: auto; }

/* La imagen se reduce si hace falta, sin perder su proporción. */
img { max-width: 100%; height: auto; }

/* Caja de proporción 16:9, cuya altura se calcula. */
.portada { width: 100%; height: auto; aspect-ratio: 16 / 9; }

Valores y conflictos habituales

  • auto deja que el navegador calcule el tamaño según el contexto. height: auto suele permitir crecer con el contenido; no equivale a una altura fija.
  • Los porcentajes necesitan una referencia: width: 100% suele tomar el ancho del bloque contenedor. Un height: 100% no significa «toda la pantalla» y, en el flujo normal, necesita una altura de referencia definida para funcionar como esperas.
  • min-content, max-content y fit-content permiten tamaños relacionados con las necesidades del contenido, en lugar de una medida fija.
  • Un máximo puede limitar el tamaño declarado y un mínimo puede ampliarlo. Si el mínimo supera al máximo, prevalece el mínimo. Evita un min-width mayor que la pantalla.
  • En elementos Flexbox o Grid, el mínimo automático puede impedir que una caja se reduzca. Cuando el diseño lo necesite, min-width: 0 o min-inline-size: 0 permite que ceda espacio; después debes decidir cómo tratar su contenido.

Prueba las dimensiones con texto largo, zoom e imágenes de distintos tamaños. No fijes una altura solo porque encaja con el texto de ejemplo: limita la capacidad del diseño para adaptarse.

Consulta: MDN · min-width.

3.4. Overflow: contenido que no cabe

overflow decide qué ocurre cuando el contenido rebasa el área disponible. Es independiente de definir el tamaño: para observar desbordamiento vertical en un bloque de texto, limita primero su altura o altura máxima.

Valores de overflow
ValorResultado
visibleEl contenido puede salir de la caja. Es el valor inicial; puede solaparse con otros elementos.
hiddenRecorta el excedente sin ofrecer barras de desplazamiento. Puede existir desplazamiento programático.
clipRecorta y no crea un contenedor desplazable, ni siquiera mediante JavaScript.
scrollCrea un área desplazable y solicita barras incluso sin desbordamiento; su apariencia depende del sistema.
autoPermite desplazarse cuando el contenido lo necesita.
.panel {
  max-height: 15rem;
  overflow: auto;
}

/* Una tabla ancha puede desplazarse dentro de su contenedor. */
.tabla-scroll { overflow-x: auto; }

/* Dos valores: primero el eje horizontal, después el vertical. */
.panel-ejes { overflow: hidden auto; }

overflow-x y overflow-y controlan cada eje. No todas las combinaciones se comportan de manera independiente: si un eje usa visible y el otro un valor distinto de visible o clip, ese visible se calcula como auto.

Para URLs o palabras largas, considera overflow-wrap: anywhere. Para mostrar puntos suspensivos en una línea necesitas combinar text-overflow con un ancho limitado, recorte y ausencia de salto de línea:

.titulo-breve {
  max-width: 20rem;
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
}

No ocultes el desbordamiento de toda la página para disimular un problema de anchura. Comprueba el origen y conserva el acceso a la información. Si creas una región desplazable, verifica su uso con teclado; cuando necesite foco propio, añade tabindex="0" y un nombre accesible, por ejemplo mediante role="region" y aria-labelledby.

Consulta: MDN · overflow.

4. Unidades, color y tipografía

Elige la unidad por su relación con el diseño. rem depende del tamaño de fuente raíz. En font-size, em depende de la fuente del padre; en muchas otras propiedades depende de la fuente del propio elemento. Los porcentajes toman una referencia que varía según la propiedad. vw se relaciona con el ancho del viewport y dvh con su alto dinámico. Un píxel CSS no equivale necesariamente a un píxel físico.

:root {
  --marca: #1e3a8a;
  --espacio: 1rem;
}
body { color: #172033; font: 1rem/1.6 system-ui, sans-serif; }
h1 { font-size: clamp(2rem, 5vw, 3.5rem); }
.articulo { width: min(100% - 2rem, 65ch); margin-inline: auto; }
a { color: var(--marca); }

Define colores compartidos con propiedades personalizadas. RGB con alfa permite controlar la transparencia de un color; opacity afecta al elemento completo y a sus descendientes. Para una imagen de fondo translúcida sin alterar el texto, utiliza una capa o pseudoelemento independiente. Los fondos decorativos no sustituyen las imágenes con contenido y texto alternativo.

Trabaja con una jerarquía de tamaños y una altura de línea cómoda. Limita el ancho de lectura, ofrece fuentes de reserva y evita justificar párrafos estrechos si genera huecos difíciles de leer. Las listas y tablas necesitan su propia separación, alineación y encabezados semánticos.

5. Posicionamiento y acabados

relative desplaza visualmente una caja conservando su espacio original. absolute sale del flujo y suele tomar como referencia el ancestro posicionado más cercano. fixed suele usar el viewport, aunque ciertos ancestros pueden cambiar ese comportamiento. sticky mantiene su lugar en el flujo y se adhiere al alcanzar un umbral dentro de sus límites de desplazamiento.

.navegacion { position: sticky; top: 0; z-index: 10; }
.tarjeta { position: relative; }
.insignia { position: absolute; top: .5rem; right: .5rem; }

z-index se interpreta dentro de contextos de apilamiento: un número muy grande no permite escapar del contexto del padre. Reserva float para envolver una imagen con texto. Para distribuir columnas usarás Flexbox o Grid. Añade bordes redondeados, sombras y gradientes con moderación; comprueba que el contraste del texto se mantiene.

.tarjeta {
  border-radius: .75rem;
  box-shadow: 0 .25rem 1rem rgb(15 23 42 / .12);
  background: linear-gradient(135deg, #fff, #eff6ff);
}
.boton { cursor: pointer; min-height: 2.75rem; }

6. Diseño responsive y medios

Un diseño responsive combina medidas flexibles, recursos adaptables y cambios de distribución. Mobile first parte de la pantalla estrecha y añade reglas con min-width cuando el contenido lo necesita. Los puntos de ruptura son decisiones del diseño, no una lista universal de dispositivos.

<meta name="viewport" content="width=device-width, initial-scale=1">

/* CSS: una columna como punto de partida */
.contenido { display: grid; gap: 1rem; }
@media (min-width: 48rem) {
  .contenido { grid-template-columns: 2fr 1fr; }
}
@media print {
  nav, .decoracion { display: none; }
  body { color: #000; background: #fff; }
}

Prueba anchos intermedios, orientación, zoom y textos largos. Un menú móvil debe poder abrirse con un botón y teclado, indicar su estado y mantener enlaces alcanzables. Oculta decoraciones cuando proceda, pero conserva la información necesaria. Comprueba también la vista de impresión.

7. Flexbox: distribuir en un eje

Flexbox organiza los hijos directos del contenedor sobre un eje principal. flex-direction define ese eje; justify-content reparte el espacio sobre él y align-items alinea en el transversal. Con flex-wrap aparecen nuevas líneas. Los elementos pueden crecer o encogerse mediante flex.

.galeria { display: flex; flex-wrap: wrap; gap: 1rem; }
.galeria > article { flex: 1 1 15rem; min-width: 0; }
.barra { display: flex; align-items: center; justify-content: space-between; }

Prueba los ejes

flex-direction: row; justify-content: flex-start;

Cambiar el orden visual no cambia automáticamente el orden del DOM ni la navegación con teclado. Mantén un orden lógico en el HTML.

8. Grid: filas y columnas

Grid permite definir filas y columnas de forma conjunta. fr reparte espacio disponible; minmax() establece un intervalo. repeat() evita repetir pistas y auto-fit ajusta el número de columnas que caben. En diseños con textos extensos, minmax(0, 1fr) evita que el mínimo intrínseco de una pista fuerce un desbordamiento.

.rejilla {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(min(100%, 15rem), 1fr));
  gap: 1rem;
}
@media (min-width: 48rem) {
  .destacada { grid-column: span 2; }
}

Puedes usar Grid para la distribución general y Flexbox dentro de una tarjeta. Elige según las relaciones entre elementos: una fila de controles suele resolverse con Flexbox; una cuadrícula que necesita alinear filas y columnas, con Grid.

10. Repaso y entrega

¿Qué diferencia hay entre un margen y un relleno?

El relleno separa el contenido del borde; el margen separa la caja de su entorno.

¿Por qué una interfaz de escritorio reducida no es necesariamente responsive?

Porque también hay que adaptar distribución, lectura e interacción, y comprobar que el contenido sigue siendo utilizable.

¿Flexbox sustituye a Grid?

Son complementarios: se pueden combinar para resolver distintas relaciones de distribución.
