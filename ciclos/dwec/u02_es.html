1. Introducción a JavaScript

JavaScript (JS) es un lenguaje de programación que permite procesar datos y dotar de comportamiento a una página web. Con él se pueden realizar cálculos, comprobar datos de un formulario y actualizar el contenido en respuesta a las acciones del usuario.

En esta unidad se trabajará con JavaScript en el navegador. Los conceptos se practicarán mediante ejemplos breves y actividades independientes.

1.1. Origen y evolución

JavaScript fue creado por Brendan Eich en 1995, durante su trabajo en Netscape. Su finalidad inicial era incorporar pequeñas interacciones a las páginas y ejecutar instrucciones en el navegador del usuario.

La aparición de distintas implementaciones hizo necesario un estándar común. Estos hitos resumen su evolución; las características que se mencionan se desarrollarán a lo largo del módulo.

  1. 1995 · Nacimiento en Netscape

    Brendan Eich crea el lenguaje para incorporar interacción a las páginas web. Inicialmente se denomina Mocha, después LiveScript y finalmente JavaScript.

  2. 1997 · Primer estándar ECMAScript

    Ecma International publica ECMA-262 para establecer unas reglas comunes entre implementaciones.

  3. 1999 · ECMAScript 3

    Incorpora expresiones regulares y manejo de excepciones. Se convierte en la base de JavaScript durante la década siguiente.

  4. 2009 · ECMAScript 5

    Añade el modo estricto, soporte nativo de JSON y nuevos métodos para trabajar con arrays.

  5. 2015 · ECMAScript 2015 (ES6)

    Una renovación importante: let, const, funciones flecha, plantillas de cadena, clases, módulos y promesas.

  6. 2017 · Funciones asíncronas

    async y await facilitan expresar operaciones asíncronas. Se estudiarán en unidades posteriores.

  7. 2020 · Nuevos recursos del lenguaje

    Se incorporan el encadenamiento opcional (?.), el operador de coalescencia nula (??) y BigInt.

1.2. JavaScript y ECMAScript

ECMAScript es la especificación que define las reglas del lenguaje: su sintaxis, sus tipos de datos y sus operaciones. Se publica como el estándar ECMA-262 de Ecma International y evoluciona mediante el trabajo del comité TC39. Los motores JavaScript implementan estas reglas.

El navegador añade herramientas para trabajar con la página, como el DOM y los eventos. Estas herramientas forman parte de las APIs web y se definen en estándares propios.

En esta unidad, JavaScript moderno se refiere al uso de prácticas actuales y características consolidadas. La evolución del lenguaje conserva compatibilidad con mucho código anterior; por ello, la documentación puede mostrar distintas formas de resolver una misma tarea.

1.3. Características del lenguaje

  • Tipado dinámico. No se declara un tipo fijo para cada variable. Los valores tienen un tipo, y una variable puede contener valores de distintos tipos durante la ejecución. Esto no elimina las reglas sobre qué operaciones admite cada valor.
  • Multiparadigma. Permite organizar un programa mediante instrucciones, funciones y objetos. En esta unidad se utilizarán principalmente instrucciones y funciones.
  • Trabajo con objetos. Los objetos agrupan datos y operaciones relacionadas. En el navegador se utilizan para representar, entre otros elementos, el documento y sus controles. Su modelo se basa en prototipos, que se estudiarán más adelante.
  • Ejecución en distintos entornos. Además de los navegadores, existen entornos como Node.js. El lenguaje es el mismo, pero las herramientas disponibles dependen del entorno.

En las páginas web es habitual la programación dirigida por eventos: se establece qué instrucciones deben ejecutarse cuando sucede algo, como pulsar un botón o modificar un campo. La función que responde a ese suceso se denomina manejador del evento.

2.2. Primeras formas de mostrar y recoger información

Una función realiza una tarea. Al llamarla, los valores escritos entre paréntesis son sus argumentos; los parámetros describen los datos que puede recibir. El retorno es el valor que devuelve la llamada. Una función asociada a un objeto se denomina método. Para invocarlo se escribe el nombre del objeto, un punto y el nombre del método, seguido de los paréntesis con sus argumentos: objeto.metodo(argumentos). En console.log("Hola"), console es el objeto y log es el método.

Las fichas presentan la forma de uso que necesitamos en esta unidad. Los nombres como mensaje o valor se sustituyen por datos concretos; ... indica que pueden pasarse más argumentos.

Mensajes en la consola

Ficha de función o método

console.log(valor1, ..., valorN)

Muestra información en la consola, sin añadirla a la página.

Parámetros: Uno o varios valores de cualquier tipo, separados por comas. En console.log("Hola"), "Hola" es el argumento que se pasa.

Devuelve: undefined; mostrar un mensaje no equivale a devolver ese mensaje.

console.log("Comienza el programa");
console.log(8 + 4);

console.log() muestra información en DevTools sin añadirla a la página. En este ejemplo aparecen un mensaje y el resultado 12. Si la consola muestra también undefined, es el valor devuelto por la llamada; no indica que haya fallado.

Diálogos del navegador

Ficha de función o método

alert(mensaje)

Muestra un aviso modal en el navegador.

Parámetros: mensaje: texto que se quiere mostrar; es opcional. Otros valores se convierten en texto.

Devuelve: undefined.

Ficha de función o método

prompt(mensaje, valorInicial)

Abre un diálogo para solicitar un texto.

Parámetros: mensaje y valorInicial: textos opcionales; el segundo rellena inicialmente el campo.

Devuelve: Una cadena al aceptar, incluso si está vacía, o null al cancelar.

Ficha de función o método

confirm(mensaje)

Solicita una confirmación mediante un diálogo.

Parámetros: mensaje: texto opcional que describe la decisión.

Devuelve: true al aceptar; false al cancelar.

alert("Bienvenido a JavaScript");
console.log(prompt("¿Cómo te llamas?"));
console.log(confirm("¿Quieres continuar?"));
  • alert() muestra un aviso que el usuario debe cerrar.
  • prompt() solicita un texto. Devuelve una cadena al aceptar, una cadena vacía si se acepta sin escribir, o null al cancelar. Incluso cuando se escribe un número, se recibe texto.
  • confirm() solicita una decisión. Devuelve true al aceptar o false al cancelar.

En los dos últimos ejemplos se obtiene primero la respuesta del diálogo y después se muestra con console.log(). Los tipos de estos valores se estudiarán en el apartado 4.

Los diálogos son modales: mientras permanecen abiertos impiden interactuar con el resto de la página. Resultan útiles para estas primeras pruebas; en las páginas interactivas se utilizarán también campos y mensajes del documento.

Puede que hayas visto utilizar la función document.write() para escribir contenido HTML en una página. Su uso está desaconsejado porque altera el documento mientras se procesa y, si se llama después de cargarlo, puede borrar el contenido existente. Además, interpretar como HTML datos no fiables puede introducir código malicioso. En esta unidad se actualizarán elementos concretos del DOM mediante herramientas como textContent.

2.3. Primer contacto con la depuración

Depurar consiste en localizar y comprender los errores de un programa. Conviene distinguir un mensaje que escribe el programador de un error detectado por el navegador:

Ficha de función o método

console.warn(valor1, ..., valorN)

Muestra un mensaje con nivel de advertencia en la consola.

Parámetros: Uno o varios valores que se mostrarán.

Devuelve: undefined; no detiene la ejecución.

Ficha de función o método

console.error(valor1, ..., valorN)

Muestra un mensaje con nivel de error en la consola.

Parámetros: Uno o varios valores que se mostrarán.

Devuelve: undefined; por sí mismo no lanza una excepción.

console.log("Información de seguimiento");
console.warn("Aviso de prueba");
console.error("Mensaje de error de prueba");

console.warn() y console.error() presentan mensajes con distinta importancia visual. Llamar a console.error() no provoca por sí mismo una excepción ni detiene el programa.

Cuando aparece un error real, la consola suele indicar su tipo, una descripción y el archivo y la línea relacionados. El enlace a esa línea ayuda a localizarlo. Si no aparecen mensajes, comprueba los filtros de la consola.

2.5. Carga y ejecución de los scripts

El navegador procesa el HTML progresivamente. Si un script se ejecuta antes de que exista el elemento que necesita, no podrá encontrarlo. Por ello, es necesario elegir cuándo debe ejecutarse el script.

Las principales opciones de carga son:

  • Script clásico sin atributos: detiene el análisis del HTML para cargar y ejecutar el código.
  • defer: descarga un script clásico externo mientras continúa el análisis y lo ejecuta cuando el HTML ya está procesado. Conserva el orden entre scripts diferidos.
  • async: descarga en paralelo y ejecuta cuando está disponible. No garantiza que el HTML esté terminado ni el orden entre scripts.
  • type="module": carga código como módulo y difiere su ejecución por defecto. Los módulos se desarrollarán en otra unidad.

En esta práctica se utilizará <script src="ej02-javascriptExterno.js" defer></script>. defer no tiene efecto en scripts clásicos escritos dentro del HTML y no implica esperar a que se descarguen todas las imágenes.

Otras opciones: eventos de cargaAmpliación

También se puede aplazar una acción hasta que ocurra un evento de carga:

  • DOMContentLoaded: se dispara cuando el HTML está procesado y los scripts diferidos han terminado. No espera a las imágenes; suele ser suficiente para comenzar a trabajar con el DOM.
  • load: espera además a recursos como imágenes y hojas de estilo, sin esperar a las imágenes con loading="lazy". Puede manejarse mediante window.onload o window.addEventListener("load", manejador).

Ficha de función o método

destino.addEventListener(tipo, manejador, opciones)

Registra una función que se ejecutará cuando ocurra un evento en el destino.

Parámetros: tipo: nombre del evento, como "click". manejador: función que recibirá el objeto del evento. opciones: configuración opcional, que se estudiará más adelante.

Devuelve: undefined. Se entrega la función, sin llamarla en ese momento.

Añade este código a ej02-javascriptExterno.js, enlazado desde el HTML con defer. Abre la consola y recarga la página:

document.addEventListener("DOMContentLoaded", function () {
    console.log("1. El HTML está procesado y el DOM está listo");
});

window.addEventListener("load", function () {
    console.log("2. Han terminado de cargar los recursos de la página");
});

La propiedad onload y el evento load. onload recibe el manejador; el nombre del evento es load. Una nueva asignación a window.onload sustituye el manejador anterior; addEventListener() permite registrar varios.

También puede escribirse como atributo de <body>. En este caso, responde al evento de carga de la ventana:

<!-- Desaconsejado: evento en el HTML -->
<body onload="console.log('Página cargada')">
    <h1>Mi página</h1>
</body>

Se desaconseja esta forma porque mezcla la estructura HTML con el comportamiento. En los ejercicios, registra el manejador desde el archivo JavaScript con window.addEventListener("load", manejador).

3. Sintaxis básica y buenas prácticas iniciales

La sintaxis establece cómo se escribe un programa válido. Las convenciones de estilo ayudan a que ese programa resulte legible y fácil de modificar. En los ejemplos de este apartado se utilizará el archivo ej02-javascriptExterno.js preparado al separar el JavaScript del HTML en el apartado 2.4.

3.1. Valores, expresiones, instrucciones y bloques

Un valor es un dato con el que trabaja el programa, como el número 12, el texto "Hola" o el valor lógico true. Cuando se escribe directamente en el código se utiliza un literal.

Una expresión es una construcción que se evalúa y produce un valor. Por ejemplo, 8 + 4 produce 12. Un literal también puede constituir una expresión.

console.log(8 + 4);

En este ejemplo, 8 + 4 es la expresión que calcula el resultado. La línea completa es una instrucción que llama a console.log() para mostrarlo. Una instrucción representa un paso del programa.

Un bloque agrupa instrucciones entre llaves. En este ejemplo se ejecutan las dos instrucciones en orden:

{
    console.log("Inicio del bloque");
    console.log("Fin del bloque");
}

Los bloques se utilizarán más adelante en estructuras de control y funciones. Las llaves delimitan el bloque; el sangrado permite reconocer visualmente su contenido.

3.2. Mayúsculas y signos de delimitación

JavaScript distingue entre mayúsculas y minúsculas. Por tanto, console.log y console.Log son nombres diferentes. Una letra incorrecta puede impedir que una instrucción funcione.

Conviene distinguir los signos que ya han aparecido:

  • Comillas: delimitan textos, como "Bienvenido".
  • Paréntesis: en una llamada, contienen los argumentos, como en console.log("Bienvenido").
  • Llaves: en los ejemplos anteriores, delimitan un bloque.

3.3. Comentarios en JavaScript

Los comentarios documentan el código y no se ejecutan:

// Comentario de una línea.
console.log("Bienvenido");

/*
   Comentario que ocupa
   varias líneas.
*/
console.log("Fin del programa");

// inicia un comentario hasta el final de la línea. /* y */ delimitan un comentario que puede ocupar varias líneas. Estos últimos no se pueden anidar.

Un comentario de línea también puede aparecer después de una instrucción. Utiliza los comentarios para explicar el propósito o el motivo de una decisión, no para repetir lo que el código ya expresa. Puedes comentar una instrucción temporalmente para probar el resto del programa:

console.log("Inicio"); // Marca el comienzo de la prueba.
// console.log("Mensaje desactivado durante la prueba");
console.log("Fin");

Los símbolos de comentario dentro de una cadena son texto: console.log("https://ejemplo.com"); muestra la dirección completa. En archivos JavaScript se usan // y /* ... */; reserva <!-- ... --> para comentarios del HTML.

3.4. Modo estricto: "use strict"

El modo estricto convierte algunos errores que podrían pasar inadvertidos en errores explícitos. En un script clásico se activa escribiendo "use strict"; al principio, antes de las instrucciones; puede haber comentarios y líneas en blanco delante:

// Archivo ej02-javascriptExterno.js
"use strict";

console.log("Programa en modo estricto");

Por ejemplo, asignar un valor a un nombre que no se ha declarado provoca un ReferenceError. Prueba este fragmento en un archivo independiente, sin una declaración previa de puntosPrueba:

"use strict";

puntosPrueba = 10; // ReferenceError: falta declarar la variable.
console.log("Fin"); // No se ejecuta porque el error detiene este script.

Sin modo estricto, esa asignación en un script clásico puede crear una variable global accidental. La solución es declarar el nombre, no quitar la directiva: let puntosPrueba = 10;. Las declaraciones se estudiarán en el apartado 4.

La directiva afecta al script donde aparece, no a todos los archivos de la página. También puede activar el modo estricto dentro de una función con parámetros simples, si se coloca al comienzo de su cuerpo. Escribirla dentro de un bloque cualquiera o después de una instrucción ordinaria no lo activa.

Scripts clásicos y módulos. En los archivos clásicos de los ejercicios, escribe "use strict"; al principio. Los scripts con type="module" ya funcionan en modo estricto automáticamente; no necesitan la directiva. El atributo defer solo afecta a la carga y ejecución: no activa el modo estricto.

4. Variables y tipos de datos

Las variables permiten asociar un nombre a un valor y utilizarlo a lo largo del programa. En los ejemplos se emplearán const y let, junto con nombres descriptivos en camelCase.

Prueba cada fragmento por separado en ej04-marcadorPuntos.js y recarga la página. Así evitarás declarar varias veces el mismo nombre al reunir ejemplos independientes.

4.1. Declaración, inicialización y reasignación

Declarar una variable introduce su nombre en el programa. Inicializarla consiste en establecer su valor inicial. Una reasignación sustituye el valor que tenía por otro.

let puntuacion = 10; // Declaración e inicialización.
console.log(puntuacion); // 10

puntuacion = 15; // Reasignación.
console.log(puntuacion); // 15

El signo = asigna un valor; no expresa una comparación. Al reasignar se escribe el nombre sin repetir let.

Con let es posible separar la declaración de la primera asignación. Mientras no se asigne otro valor, la variable contiene undefined:

let mensaje;
console.log(mensaje); // undefined

mensaje = "Bienvenido";
console.log(mensaje); // Bienvenido

Declara las variables antes de utilizarlas. Usar un nombre que no se ha declarado provoca un ReferenceError; no es lo mismo que leer una variable declarada cuyo valor es undefined.

4.2. Identificadores y nombres descriptivos

Un identificador es un nombre que permite referirse a un elemento del programa, como una variable o una función. Al declarar una variable se elige su identificador, que debe respetar las reglas del lenguaje y expresar su significado.

  • Puede comenzar por una letra, un guion bajo (_) o el signo $. También se admiten muchas letras Unicode.
  • Puede incluir números, pero no comenzar por ellos.
  • No puede contener espacios ni guiones medios.
  • No se utilizan palabras reservadas como if, class o return.
  • Las mayúsculas distinguen nombres: nombreUsuario y NombreUsuario son identificadores diferentes.

Se empleará camelCase: la primera palabra comienza en minúscula y las siguientes en mayúscula, como nombreUsuario, numeroIntentos o mostrarMensaje.

El nombre debe expresar su significado. Por ejemplo, numeroIntentos comunica más información que n. Para funciones que realizan una acción conviene utilizar un verbo, como mostrarMensaje. Se mantendrá un criterio de idioma coherente.

4.3. Elegir entre const y let

Utiliza const como opción habitual y let cuando el programa necesite reasignar la variable.

const nombreCurso = "DWEC";
let intentosRestantes = 3;

intentosRestantes = 2;
console.log(nombreCurso, intentosRestantes);
  • const requiere un valor inicial en su declaración y no permite reasignarlo.
  • let permite establecer un valor inicial y cambiarlo posteriormente.
  • Ninguna de las dos permite volver a declarar el mismo nombre en el mismo ámbito.

En código anterior puede aparecer var. Sus reglas de ámbito son diferentes; en esta unidad se utilizarán const y let.

const con funciones y otros valoresAmpliación

const puede asociar un nombre a una función, ya que las funciones también son valores. En este ejemplo se utiliza una expresión de función con la palabra function:

const saludar = function () {
    console.log("Hola");
};

const despedir = function () {
    console.log("Hasta pronto");
};

saludar();
despedir();

Los nombres saludar y despedir permiten invocar las funciones y no pueden reasignarse. Las llamadas se sitúan después de las declaraciones. Su sintaxis se explicará en el apartado de funciones.

const también permite guardar una referencia a un elemento de la página (DOM), a un objeto o a un array (una lista de valores), además de valores de configuración. El nombre debe seguir apuntando al mismo elemento, objeto o array, pero su contenido puede cambiar: por ejemplo, puedes modificar una propiedad de usuario, aunque no asignar otro objeto a usuario. Por eso, const impide la reasignación, pero no vuelve inmutable el contenido:

const usuario = { nombre: "Ana" };
usuario.nombre = "Luis";
console.log(usuario.nombre); // Luis

La ventaja de const frente a let es que deja clara la intención de no reasignar el nombre y permite detectar una reasignación accidental, porque produce un error. Utiliza const cuando no necesites sustituir el valor y let cuando deba cambiar; la elección ayuda a entender y mantener el código.

Los objetos y arrays se estudiarán más adelante. Para constantes de configuración puede emplearse MAYUSCULAS_CON_GUIONES_BAJOS, como MAX_INTENTOS; declarar con const no obliga a escribir todos los nombres en mayúsculas.

4.4. Tipos de datos de uso inicial

El tipo describe la clase de valor con la que trabaja el programa. En estos primeros ejercicios se utilizarán los siguientes:

  • number: representa números, tanto enteros como decimales. Ejemplos: 18 y 7.5. El separador decimal en el código es el punto.
  • string: representa texto delimitado por comillas. Ejemplos: "Ana", "18" y "". Un número entre comillas es texto; una cadena vacía también es texto.
  • boolean: admite los valores true y false, escritos sin comillas. Permite representar estados como «activo» o «inactivo».
  • undefined: es el valor de una variable declarada con let a la que todavía no se ha asignado otro valor.
  • null: se utiliza para representar de forma explícita la ausencia de un valor.
const edad = 18;
const nombre = "Ana";
const matriculaActiva = true;
let observaciones;
const tutorAsignado = null;

console.log(edad, nombre, matriculaActiva);
console.log(observaciones, tutorAsignado);

undefined puede aparecer también en otras situaciones, como el resultado de una llamada a console.log(). null expresa una ausencia explícita, como ocurre al cancelar prompt(). Ninguno equivale a un texto vacío.

4.5. Tipado dinámico y typeof

JavaScript tiene tipado dinámico: una variable no queda asociada a un tipo fijo. El operador typeof consulta el tipo de un valor y devuelve una cadena con su nombre.

let dato = 42;
console.log(typeof dato); // "number"

dato = "cuarenta y dos";
console.log(typeof dato); // "string"

La reasignación es válida, pero conviene mantener un significado y un tipo coherentes para cada variable cuando sea posible. Esto facilita entender el programa.

console.log(typeof 7.5);      // "number"
console.log(typeof "7.5");    // "string"
console.log(typeof false);    // "boolean"
console.log(typeof undefined); // "undefined"
console.log(typeof null);     // "object"

El caso de null. Por una particularidad histórica, typeof null devuelve "object". Sin embargo, null es un valor primitivo que representa ausencia, no un objeto con propiedades.

4.6. Cadenas e interpolación

Las cadenas sencillas pueden escribirse con comillas dobles o simples. El delimitador de cierre debe coincidir con el de apertura. Las comillas de otro tipo pueden formar parte del texto:

const saludo = "Hola";
const aviso = 'Pulsa "Aceptar" para continuar';
console.log(saludo, aviso);

El operador + permite concatenar, es decir, unir cadenas. Las plantillas de cadena utilizan acentos graves (`) y permiten insertar valores mediante ${expresion}.

const nombre = "Ana";
const curso = "DWEC";

console.log("Hola, " + nombre + ". Bienvenida a " + curso + ".");
console.log(`Hola, ${nombre}. Bienvenida a ${curso}.`);

Ambas instrucciones muestran el mismo mensaje. La interpolación facilita leer textos que combinan varias variables. Las comillas simples y dobles no interpretan ${...}.

4.7. Ámbito de bloque

El ámbito determina desde dónde se puede utilizar una variable. Una variable declarada con let o const dentro de un bloque está disponible en ese bloque y en los que contiene, pero no fuera de él.

const centro = "IES Ejemplo";

{
    const grupo = "2DAW";

    console.log(grupo);  // 2DAW
}

console.log(centro); // IES Ejemplo
// console.log(grupo); // Fuera del bloque: ReferenceError.

El bloque puede acceder a centro, declarado en el ámbito exterior. En cambio, el código exterior no puede acceder a grupo. Conviene declarar cada variable cerca de donde se utiliza y limitar su ámbito a lo necesario.

5. Operadores, expresiones y conversiones

Los operadores permiten realizar cálculos, comparar valores y combinar condiciones. Los valores sobre los que actúan se denominan operandos: en 6 + 2, el operador es + y los operandos son 6 y 2. Ejecuta los ejemplos de este apartado por separado en la consola o en ej08-compararValores.js.

5.1. Operadores aritméticos y de asignación

OperadorOperaciónEjemplo
+Suma9 + 4 → 13
-Resta9 - 4 → 5
*Multiplicación9 * 4 → 36
/División9 / 4 → 2.25
%Resto de la división9 % 4 → 1
**Potencia3 ** 2 → 9
++Incremento: aumenta la variable en 1let n = 4; n++; → n vale 5
--Decremento: reduce la variable en 1let n = 4; n--; → n vale 3

% no calcula porcentajes. Por ejemplo, para obtener el 20 % de una cantidad se multiplica por 20 / 100.

La asignación = guarda un valor. Los operadores compuestos permiten actualizar una variable a partir de su valor anterior:

let puntos = 10;
puntos += 5; // Equivale a puntos = puntos + 5.
puntos -= 2; // Equivale a puntos = puntos - 2.
console.log(puntos); // 13

También existen *=, /=, %= y **=. Multiplican, dividen, calculan el resto o elevan a una potencia y guardan el resultado en la misma variable:

let cantidad = 12;
cantidad *= 2;  // 24
cantidad /= 3;  // 8
cantidad %= 3;  // 2
cantidad **= 3; // 8
console.log(cantidad); // 8

Incremento y decremento: prefijo y sufijo

++ y -- modifican la variable, por lo que utilizaremos let. Escritos delante (++contador), devuelven el valor después del cambio; escritos detrás (contador++), devuelven el valor anterior. En ambos casos la variable termina incrementada en una unidad. Lo mismo sucede con --, pero restando una unidad:

let contador = 3;
console.log(contador++); // 3: devuelve el valor anterior.
console.log(contador);   // 4: la variable ya ha cambiado.
console.log(++contador); // 5: incrementa y devuelve el nuevo valor.
console.log(contador--); // 5: devuelve el valor anterior y deja 4.
console.log(--contador); // 3: decrementa y devuelve el nuevo valor.

Si solo necesitas cambiar un contador, escribe contador++; o contador--; como instrucciones independientes. Evita modificar la misma variable varias veces dentro de una expresión: dificulta entender el resultado.

5.2. Comparaciones e igualdad estricta

Las comparaciones producen un booleano. Los operadores >, <, >= y <= comprueban si un valor es mayor, menor, mayor o igual, o menor o igual que otro.

const nota = 7;
console.log(nota >= 5); // true
console.log(nota < 5);  // false
console.log(nota === 7); // true
console.log(nota !== 7); // false

Se utilizarán === y !== para comprobar igualdad y desigualdad estrictas. No convierten los operandos a otro tipo: 7 === "7" es false. Los operadores == y != pueden realizar conversiones implícitas y se evitarán en estos ejercicios.

Asignar no es comparar. nota = 5 cambia el valor de una variable; nota === 5 consulta si su valor es el número 5. Para comparar cantidades recibidas como texto, conviértelas primero a números.

5.3. Operadores lógicos y coalescencia nula

Cuando se trabaja con booleanos, estos operadores permiten expresar condiciones compuestas:

  • && (Y): el resultado es true si ambas condiciones son verdaderas.
  • || (O): el resultado es true si al menos una condición es verdadera.
  • ! (NO): invierte el valor lógico.
const tieneEntrada = true;
const salaAbierta = false;

console.log(tieneEntrada && salaAbierta); // false
console.log(tieneEntrada || salaAbierta); // true
console.log(!salaAbierta); // true

&& y || evalúan de izquierda a derecha y pueden omitir el segundo operando si el primero determina el resultado. Es la evaluación en cortocircuito. Con otros tipos de datos devuelven uno de sus operandos, no necesariamente un booleano. Al comprobarlos como condición, valores como false, 0, "", null, undefined y NaN se consideran falsos; se denominan falsy. Los demás se consideran verdaderos (truthy). || devuelve el primer operando si es truthy y, si no, evalúa y devuelve el segundo; && devuelve el primero si es falsy y, si no, evalúa y devuelve el segundo.

Coalescencia nula: ??

valor ?? alternativa devuelve la alternativa únicamente cuando valor es null o undefined. Permite dar un valor predeterminado cuando falta un dato, conservando valores válidos como 0, false o una cadena vacía. No modifica la variable y solo evalúa la alternativa si la necesita:

let nombre;
console.log(nombre ?? "Sin nombre"); // "Sin nombre"
console.log(null ?? "Sin dato");     // "Sin dato"
console.log(0 ?? 10);                // 0
console.log(false ?? true);          // false
console.log("" ?? "Sin texto");      // ""
console.log(0 || 10);                // 10: || también sustituye los valores falsy.

?? y || no son equivalentes. Si cero significa «ninguna unidad», unidades ?? 1 conserva ese cero; unidades || 1 lo sustituye por uno. Elige según qué valores consideres ausentes.

Asignación lógica: ??=, ||= y &&=

Estos operadores solo asignan el valor de la derecha cuando se cumple su condición. Si no se cumple, conservan el valor actual y no evalúan la expresión de la derecha:

  • dato ??= alternativa: asigna si dato es null o undefined.
  • dato ||= alternativa: asigna si dato es falsy, incluido 0, false o "".
  • dato &&= nuevoValor: asigna si dato es truthy.
let alias;
alias ??= "Invitado";
console.log(alias); // "Invitado"

let unidades = 0;
unidades ??= 1;
console.log(unidades); // 0: no es null ni undefined.

let titulo = "";
titulo ||= "Sin título";
console.log(titulo); // "Sin título"

let aviso = "Pendiente";
aviso &&= "Revisado";
console.log(aviso); // "Revisado"

Apoyo: operadores bit a bit

Con valores Number, estos operadores trabajan sobre enteros de 32 bits. & combina los bits mediante AND y ~ invierte los bits; son distintos de los operadores lógicos && y !. Para conservar únicamente los ocho bits de un octeto usa valor & 255.

numero << 1 desplaza un bit a la izquierda; numero >> 1, a la derecha conservando el signo. En enteros positivos pequeños sirven para multiplicar por 2 o dividir entre 2 descartando la parte fraccionaria. No equivalen en general a la aritmética habitual: convierten a enteros de 32 bits y pueden desbordar.

numero.toString(2) devuelve una cadena binaria y parseInt(texto, 2) convierte una cadena binaria a número. Puedes completar los ceros iniciales hasta tener ocho bits por octeto.

5.4. Precedencia y paréntesis

La precedencia determina cómo se agrupan las operaciones. La multiplicación se realiza antes que la suma, salvo que los paréntesis indiquen otra agrupación:

console.log(4 + 3 * 2);   // 10
console.log((4 + 3) * 2); // 14

En expresiones lógicas, ! tiene mayor prioridad que &&, y este mayor que ||. Utiliza paréntesis para hacer explícita la intención cuando combines varias operaciones.

No se puede mezclar ?? directamente con || o && sin paréntesis: produce un SyntaxError. Por ejemplo, (null ?? 0) || 10 es válido y devuelve 10; null ?? 0 || 10 no es válido.

5.5. Conversión explícita de tipos

Cuando un dato no tiene el tipo necesario, puede convertirse de forma explícita. La conversión produce un nuevo valor; no modifica por sí sola la variable original.

Ficha de función o método

Number(valor)

Convierte un valor en un número.

Parámetros: valor: dato que se quiere convertir. Una cadena vacía o formada por espacios se convierte en 0.

Devuelve: El número obtenido, o NaN si la conversión de un texto no es válida.

Ficha de función o método

String(valor)

Obtiene la representación textual de un valor.

Parámetros: valor: dato que se quiere convertir.

Devuelve: Una cadena.

Ficha de función o método

Boolean(valor)

Convierte un valor según las reglas de truthy y falsy.

Parámetros: valor: dato que se quiere evaluar. Por ejemplo, "false" es una cadena no vacía y produce true.

Devuelve: true o false.

const texto = "24";
const numero = Number(texto);
console.log(numero + 1); // 25
console.log(typeof texto); // "string"

console.log(String(24));    // "24"
console.log(Boolean(1));    // true
console.log(Boolean(0));    // false
console.log(Boolean(""));   // false
console.log(Boolean("false")); // true
  • Number() convierte a número. Por ejemplo, Number("6.5") produce 6.5.
  • String() obtiene una representación textual.
  • Boolean() obtiene un valor lógico. Una cadena no vacía, incluso "false" o "0", se convierte en true.

5.6. Errores habituales al operar con datos

El operador + también concatena cadenas. Al combinar un número con una cadena se obtiene texto:

console.log("12" + 3);         // "123"
console.log(Number("12") + 3); // 15
console.log("12" - 3);         // 9: conversión implícita

Conviene convertir antes de operar, sin depender de que cada operador trate el texto de una forma distinta. Si una conversión numérica falla, se obtiene NaN (Not a Number):

Ficha de función o método

Number.isNaN(valor)

Comprueba si el valor es exactamente NaN, sin convertirlo.

Parámetros: valor: dato que se quiere comprobar.

Devuelve: true para NaN; false para cualquier otro valor.

const cantidad = Number("doce");
console.log(cantidad); // NaN
console.log(Number.isNaN(cantidad)); // true

Para detectar NaN, utiliza Number.isNaN(); compararlo mediante === NaN no funciona. NaN pertenece al tipo number.

Convertir no equivale a validar. Number(""), Number(" ") y Number(null) producen 0. Por ello, una entrada vacía o un diálogo cancelado deben comprobarse antes de interpretar el resultado como una cantidad.

El DOM (Document Object Model) representa el documento mediante un árbol de objetos. JavaScript puede consultar esos objetos y modificar el contenido de la página. En este apartado los cambios se realizarán al ejecutar el script; la respuesta a acciones del usuario se estudiará con los eventos.

6.1. El documento como árbol de objetos

El objeto document representa el documento cargado. Los elementos HTML, como un párrafo o un campo de entrada, son nodos del árbol y tienen propiedades y métodos. Por ejemplo, textContent es una propiedad que contiene texto y querySelector() es un método de búsqueda.

Utiliza esta página de prueba con un archivo ej10-seleccionarElementos.js en la misma carpeta. Contiene los elementos necesarios para los ejemplos siguientes:

<!DOCTYPE html>
<html lang="es">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Pruebas con el DOM</title>
    <script src="ej10-seleccionarElementos.js" defer></script>
</head>
<body>
    <h1 id="titulo">Pruebas con el DOM</h1>

6.2. Selección de elementos

El DOM ofrece métodos específicos para buscar por identificador, clase o etiqueta. Los nombres distinguen mayúsculas y minúsculas:

Ficha de función o método

document.getElementById(id)

Busca un elemento por su identificador.

Parámetros: id: cadena con el identificador, sin el signo #.

Devuelve: El elemento encontrado o null.

Ficha de función o método

document.getElementsByClassName(clases)

Busca los elementos que tienen las clases indicadas.

Parámetros: clases: nombres de clase sin punto, separados por espacios si se indican varios.

Devuelve: Una HTMLCollection viva, que se actualiza al cambiar el documento; puede estar vacía.

Ficha de función o método

document.getElementsByTagName(etiqueta)

Busca elementos por su nombre de etiqueta.

Parámetros: etiqueta: cadena como "p" o "input"; "*" selecciona todas las etiquetas.

Devuelve: Una HTMLCollection viva, que puede estar vacía.

  • document.getElementById("titulo"): devuelve el elemento con ese identificador, o null. El identificador se escribe sin #.
  • document.getElementsByClassName("aviso"): devuelve los elementos con esa clase, sin escribir el punto.
  • document.getElementsByTagName("p"): devuelve los elementos de esa etiqueta.
const titulo = document.getElementById("titulo");
const avisos = document.getElementsByClassName("aviso");
const parrafos = document.getElementsByTagName("p");

console.log(titulo.textContent);
console.log(avisos.length);   // 1 en la página de prueba.
console.log(parrafos.length); // 2 en la página de prueba.

Los dos métodos en plural devuelven una HTMLCollection, incluso si solo hay una coincidencia. Se consulta su tamaño con length y su primer elemento con [0], si existe. Estas colecciones son vivas: se actualizan cuando cambian las coincidencias en el DOM.

Selección mediante CSS

Ficha de función o método

document.querySelector(selector)

Busca el primer elemento que coincide con un selector CSS.

Parámetros: selector: cadena con un selector válido, por ejemplo "#saludo" o ".aviso".

Devuelve: El primer Element encontrado o null si no hay coincidencias.

Ficha de función o método

document.querySelectorAll(selector)

Busca todos los elementos que coinciden con un selector CSS.

Parámetros: selector: cadena con un selector CSS válido.

Devuelve: Una NodeList estática: no se actualiza automáticamente al cambiar el documento. Puede estar vacía.

querySelector() y querySelectorAll() permiten utilizar selectores CSS, desde una etiqueta hasta una combinación de clases y atributos:

const titulo = document.querySelector("#titulo");
const aviso = document.querySelector(".aviso");
const parrafos = document.querySelectorAll("p");

console.log(titulo.textContent);
console.log(aviso.textContent);
console.log(parrafos.length); // 2

querySelector() devuelve la primera coincidencia o null. querySelectorAll() devuelve una NodeList estática: no se actualiza automáticamente si después se añaden o eliminan coincidencias. Cuando no encuentra elementos, devuelve una colección vacía.

¿Cuál usar hoy? Los métodos getElementById(), getElementsByClassName() y getElementsByTagName() siguen vigentes. En código moderno es habitual utilizar querySelector() y querySelectorAll() por su flexibilidad; serán la opción general de este curso. Para buscar un identificador concreto, getElementById() sigue siendo una opción directa y adecuada.

6.3. Leer y modificar el contenido

La propiedad textContent permite leer o sustituir el texto de un elemento:

const mensaje = document.querySelector("#mensaje");
console.log(mensaje.textContent); // Texto inicial
mensaje.textContent = "El contenido ha cambiado";

Si el elemento contiene otros elementos, asignar textContent sustituye todo su contenido por texto. Las etiquetas escritas en la cadena se muestran literalmente.

innerHTML lee o sustituye el contenido interpretándolo como HTML:

const mensaje = document.querySelector("#mensaje");
mensaje.innerHTML = "<strong>Aviso:</strong> sesión iniciada";

Texto o HTML. Utiliza textContent para mostrar texto y datos introducidos por el usuario. Reserva innerHTML para HTML controlado: insertar contenido no fiable puede permitir que se ejecute código malicioso. Los cambios en el DOM no modifican el archivo HTML guardado en disco.

outerHTML incluye también la etiqueta del propio elemento. En la página de prueba, ejecuta este fragmento tras recargar:

const mensaje = document.querySelector("#mensaje");
console.log(mensaje.innerHTML); // Texto inicial
console.log(mensaje.outerHTML);
// <p id="mensaje" class="aviso">Texto inicial</p>

mensaje.outerHTML = '<div id="mensaje" class="aviso">Nuevo elemento</div>';
  • textContent: lee o sustituye el texto; no interpreta etiquetas.
  • innerHTML: lee o sustituye el HTML interior; conserva el elemento contenedor.
  • outerHTML: lee o sustituye el elemento completo, con su etiqueta y su contenido.

Tras asignar outerHTML, la variable mensaje sigue apuntando al elemento antiguo, ya separado del documento. Si necesitas trabajar con el nuevo, vuelve a seleccionarlo. Usa tanto innerHTML como outerHTML solo con HTML controlado; para datos del usuario utiliza textContent.

7. Estructuras de control

Un programa ejecuta sus instrucciones en orden, pero puede necesitar elegir entre varias acciones o repetir una tarea. Las estructuras de control permiten tomar estas decisiones. Ejecuta cada ejemplo por separado en ej13-tomarDecisiones.js y modifica los datos para comprobar las distintas posibilidades.

7.1. Condiciones y valores truthy y falsy

Una condición es una expresión cuyo valor se interpreta como verdadero o falso. Puede ser una comparación, como edad >= 18, o una variable booleana, como sesionActiva.

Si el valor no es booleano, JavaScript lo interpreta según las reglas de Boolean():

  • Falsy: valores que se interpretan como falsos. Entre los tipos estudiados están false, 0 (también -0), "", null, undefined y NaN.
  • Truthy: valores que se interpretan como verdaderos. Por ejemplo, un número distinto de cero o una cadena no vacía, incluidas "0", "false" y " ".

Cuando se comprueba un dato concreto, una condición explícita suele expresar mejor la intención: cantidad === 0 comprueba un cero, mientras que !cantidad acepta cualquier valor falsy.

7.2. if, else if y else

if ejecuta un bloque cuando la condición se interpreta como verdadera. El bloque opcional else se ejecuta en caso contrario:

const edad = 16;

if (edad >= 18) {
    console.log("Mayor de edad");
} else {
    console.log("Menor de edad");
}

Para distinguir más alternativas se añade else if. Las condiciones se comprueban de arriba abajo y se ejecuta únicamente la primera rama que corresponde:

const temperatura = 24;

if (temperatura < 15) {
    console.log("Temperatura baja");
} else if (temperatura < 25) {
    console.log("Temperatura moderada");
} else {
    console.log("Temperatura alta");
}

Al llegar al segundo caso ya se sabe que la temperatura no es menor que 15. El orden importa: colocar primero una condición demasiado general puede impedir que se alcancen las siguientes.

Escritura de las condiciones. Utiliza llaves incluso si el bloque contiene una sola instrucción. No escribas ; entre la condición y la llave de apertura. Para comparar emplea ===, no la asignación =.

7.3. Combinar condiciones y validar datos

Los operadores &&, || y ! permiten combinar comprobaciones sin encadenar muchos bloques:

const tieneEntrada = true;
const salaAbierta = true;

if (tieneEntrada && salaAbierta) {
    console.log("Puedes acceder");
} else {
    console.log("No se cumplen las condiciones de acceso");
}

Ficha de función o método

texto.trim()

Elimina los espacios en blanco de los extremos de una cadena.

Parámetros: No recibe parámetros. Se invoca sobre la cadena que se quiere tratar.

Devuelve: Una nueva cadena; no modifica la original ni elimina los espacios interiores.

Para procesar una entrada textual, comprueba primero si está vacía y después si la conversión es válida. trim() devuelve una cadena sin espacios en blanco al principio ni al final:

const texto = " 6 ";
const cantidad = Number(texto);

if (texto.trim() === "") {
    console.log("Introduce una cantidad");
} else if (Number.isNaN(cantidad) || cantidad < 0) {
    console.log("Introduce un número igual o mayor que cero");
} else {
    console.log(`Cantidad aceptada: ${cantidad}`);
}

El ejemplo presupone que texto es una cadena. Si procede de prompt(), comprueba antes si es null, porque cancelar el diálogo no devuelve texto y no permite llamar a trim().

7.4. switch: alternativas según un valor

switch resulta útil cuando una expresión puede coincidir con varios valores concretos. Cada case representa una alternativa:

const estado = "enviado";

switch (estado) {
    case "pendiente":
        console.log("Preparando el envío");
        break;
    case "enviado":
        console.log("En camino");
        break;
    case "entregado":
        console.log("Entrega completada");
        break;
    default:
        console.log("Estado desconocido");
}

La coincidencia se comprueba mediante igualdad estricta: case 1 no coincide con "1". break sale del switch; si se omite, la ejecución continúa por las instrucciones de los casos siguientes. default es opcional y se utiliza cuando no hay coincidencia.

Para comprobar intervalos, como una temperatura entre dos límites, suele resultar más claro utilizar if y else if.

7.6. Repeticiones con for, while y do...while

Un bucle repite un bloque de instrucciones. Cada ejecución del bloque es una iteración. for reúne la inicialización, la condición de continuidad y la actualización:

for (let numero = 1; numero <= 3; numero++) {
    console.log(numero);
}
// Muestra 1, 2 y 3.

Primero se inicializa numero. Antes de cada iteración se comprueba numero <= 3; si es verdadera, se ejecuta el bloque y después numero++. Al dejar de cumplirse la condición, el bucle termina. La variable declarada con let en la cabecera no está disponible fuera del bucle.

while comprueba la condición antes de ejecutar el bloque. Puede no ejecutarlo ninguna vez:

let pendientes = 3;

while (pendientes > 0) {
    console.log(`Quedan ${pendientes}`);
    pendientes--;
}

do...while comprueba la condición al final, por lo que el bloque se ejecuta al menos una vez:

let intentos = 0;

do {
    console.log("Se realiza un intento");
    intentos++;
} while (intentos < 1);

El bucle debe poder terminar. Comprueba que la actualización acerca el programa al final de la repetición. Una condición que permanece verdadera puede bloquear la página. No uses un bucle para esperar a que el usuario pulse un botón: esa interacción se gestionará mediante eventos.

break termina el bucle más cercano; continue omite el resto de la iteración actual. En un for, después de continue se realiza la actualización y se vuelve a comprobar la condición. En estos primeros ejemplos basta con condiciones de finalización claras.

7.7. Recorrer elementos del DOM con for...of

for...of recorre los valores de una colección iterable. Se puede utilizar con el resultado de querySelectorAll() para actuar sobre varios elementos:

const parrafos = document.querySelectorAll("p");

for (const parrafo of parrafos) {

8. Eventos e interacción con el usuario

Los ejemplos anteriores se ejecutaban al cargar la página. Los eventos permiten responder a acciones posteriores: activar un botón, escribir en un campo o enviar un formulario. La respuesta puede leer datos, tomar decisiones y actualizar el DOM.

8.1. Eventos y manejadores

Un evento es una notificación de que ha ocurrido algo. Un manejador es una función que se ejecuta cuando se recibe esa notificación. Registrar un manejador establece la respuesta; no la ejecuta en ese momento.

Secuencia: acción del usuario → evento → ejecución del manejador → actualización de la página.

En este apartado se introducirá la forma mínima de una función: function nombre() { ... } agrupa instrucciones bajo un nombre. Las funciones y sus distintas formas de escritura se desarrollarán en el apartado 9.

Utiliza esta página de prueba y un archivo ej17-responderAccion.js en la misma carpeta. Prueba cada ejemplo JavaScript por separado, sustituyendo el contenido del archivo y recargando la página:

<!DOCTYPE html>

8.2. Registrar manejadores con addEventListener()

elemento.addEventListener("evento", manejador) asocia una función a un evento del elemento. El nombre del evento se escribe sin el prefijo on: "click", no "onclick".

Función del ejemplo

mostrarSaludo()

Actualiza el párrafo con un saludo.

Parámetros: No declara parámetros; utiliza el elemento mensaje del ejemplo.

Devuelve: undefined.

    mensaje.textContent = "Hola, bienvenido a la página";
}

El navegador ejecuta mostrarSaludo cada vez que se activa el botón. Un botón HTML puede activarse tanto con el ratón como con el teclado.

Pasar la función, no ejecutarla. Escribe mostrarSaludo como segundo argumento. Si escribes mostrarSaludo(), la función se ejecuta durante el registro y se pasa su resultado en lugar del manejador.

Registra los manejadores cuando los elementos ya existan, como ocurre al usar defer. addEventListener() permite asociar varias funciones a un mismo evento y mantiene el comportamiento en el archivo JavaScript.

8.3. Eventos básicos: click, input, change y submit

  • click: responde a la activación de un elemento, como un botón.
  • input: se produce al modificar un campo mediante una acción del usuario. Permite actualizar una vista mientras se escribe.
  • change: indica que se ha confirmado un cambio. En campos de texto suele producirse al abandonar el campo tras modificarlo; en un selector, al confirmar una opción.
  • submit: se produce en el formulario cuando se solicita su envío, por ejemplo mediante su botón o pulsando Intro en un campo apropiado.

Este ejemplo muestra el nombre mientras se escribe y registra cuándo se confirma el cambio:

Función del ejemplo

mostrarNombre() y confirmarCambio()

La primera muestra el valor del campo en el párrafo; la segunda lo registra en la consola.

Parámetros: No declaran parámetros; consultan el campo del ejemplo.

Devuelve: undefined en ambos casos.

const campo = document.querySelector("#nombre");
const mensaje = document.querySelector("#mensaje");

    mensaje.textContent = campo.value;
}

function confirmarCambio() {
    console.log("Cambio confirmado:", campo.value);

8.4. El objeto del evento y currentTarget

El navegador entrega al manejador un objeto con información del evento. Para utilizarlo se añade un parámetro, que aquí llamaremos event:

Función del ejemplo

mostrarEntrada(event)

Muestra el valor del campo y registra el tipo de evento.

Parámetros: event: objeto que proporciona el navegador al ejecutar el manejador.

Devuelve: undefined.

const campo = document.querySelector("#nombre");
const mensaje = document.querySelector("#mensaje");

function mostrarEntrada(event) {
    const elemento = event.currentTarget;
    mensaje.textContent = elemento.value;
    console.log(event.type); // input
}

campo.addEventListener("input", mostrarEntrada);
  • event.type contiene el nombre del evento.
  • event.currentTarget referencia el elemento donde se registró el manejador que se está ejecutando.
  • event.target identifica el destino original del evento. Puede ser un elemento interior: al pulsar un icono dentro de un botón, el destino puede ser el icono y currentTarget el botón.

Utilizar currentTarget facilita compartir un mismo manejador entre varios elementos. En estos ejemplos se consulta durante la ejecución del manejador; la propagación de eventos se estudiará más adelante.

8.5. Comportamiento predeterminado y preventDefault()

Ficha de función o método

event.preventDefault()

Cancela la acción predeterminada de un evento cancelable, como el envío de un formulario.

Parámetros: No recibe parámetros. Se invoca sobre el objeto del evento.

Devuelve: undefined. No detiene la propagación del evento.

Algunos eventos tienen una acción predeterminada: un enlace navega y un formulario inicia su envío. event.preventDefault() permite cancelar esa acción cuando el evento es cancelable.

Para procesar el formulario en la página, registra submit en el propio formulario. Así se atiende el envío aunque no se active el botón con el ratón:

Función del ejemplo

procesarFormulario(event)

Cancela el envío, comprueba el nombre y actualiza el mensaje.

Parámetros: event: objeto del evento submit recibido del navegador.

Devuelve: undefined.

const formulario = document.querySelector("#formulario");
const campo = document.querySelector("#nombre");
const mensaje = document.querySelector("#mensaje");

function procesarFormulario(event) {
    event.preventDefault();
    const nombre = campo.value.trim();

    if (nombre === "") {
        mensaje.textContent = "Escribe un nombre";
    } else {
        mensaje.textContent = `Hola, ${nombre}`;
    }
}

formulario.addEventListener("submit", procesarFormulario);

La página muestra el saludo sin realizar el envío convencional. El atributo required hace que el navegador compruebe el campo: si está vacío, la validación nativa impide el envío y no se produce submit. La comprobación con trim() rechaza además una entrada formada solo por espacios.

Cancelar la acción no detiene el programa. preventDefault() no termina el manejador ni detiene la propagación del evento. Las instrucciones que aparecen después siguen ejecutándose.

Una interacción sencilla puede organizarse en tres pasos: leer los datos actuales, comprobarlos o procesarlos y actualizar el DOM. La lectura de value debe realizarse dentro del manejador cuando se necesita el valor que tiene el campo en ese momento.

9. Funciones: organizar y reutilizar código

Una función agrupa instrucciones para realizar una tarea. Puede recibir datos y devolver un resultado. Permite reutilizar una operación y separar el programa en partes comprensibles. En el apartado anterior se utilizaron funciones como manejadores; ahora se estudiará cómo definirlas y utilizarlas.

9.2. Parámetros, argumentos y valores predeterminados

Los parámetros son los nombres que aparecen en la definición. Los argumentos son los valores que se proporcionan al llamar:

Función del ejemplo

Muestra un saludo personalizado. Es una nueva versión de saludar, independiente del ejemplo del apartado 4.

Parámetros: nombre: cadena con el nombre. saludo: cadena opcional; su valor predeterminado es "Hola".

Devuelve: undefined; muestra el mensaje, pero no lo devuelve.

    console.log(`${saludo}, ${nombre}`);
}

nombre y saludo son parámetros. En la segunda llamada, los argumentos son "Luis" y "Buenos días", que se asignan por posición.

9.3. Devolver resultados con return

return termina la ejecución de la función y entrega un valor al código que la llamó. Ese valor puede guardarse o utilizarse en otra expresión:

Función del ejemplo

calcularArea(base, altura)

Calcula el área de un rectángulo.

Parámetros: base y altura: números que representan sus dimensiones.

Devuelve: El número obtenido al multiplicar base por altura.

function calcularArea(base, altura) {
    return base * altura;
}

const area = calcularArea(6, 4);
console.log(area);     // 24
console.log(area * 2); // 48

Devolver y mostrar son operaciones distintas. console.log() escribe en la consola; no establece el resultado de la función que lo contiene:

Función del ejemplo

mostrarDoble(numero)

Muestra en la consola el doble de un número.

Parámetros: numero: número que se quiere duplicar.

Devuelve: undefined.

function mostrarDoble(numero) {
    console.log(numero * 2);
}

const resultado = mostrarDoble(5); // Muestra 10.
console.log(resultado);          // undefined

Si se alcanza el final sin ejecutar un return con valor, la función devuelve undefined. También puede escribirse return; para terminarla sin proporcionar otro resultado.

El retorno termina la llamada. Las instrucciones posteriores al return ejecutado no se alcanzan. Escribe la expresión devuelta en la misma línea que return; un salto de línea justo después puede hacer que se devuelva undefined.

9.4. Ámbito local y variables externas

Los parámetros y las variables declaradas dentro de una función son locales a ella. La función puede acceder a variables de su ámbito exterior:

Devuelve: Una cadena con la presentación.

    const texto = `${nombre} estudia en ${centro}`;

9.5. Funciones como valores y expresiones de función

Las funciones también son valores. Se pueden guardar en una variable y pasar como argumento, como ocurre al registrar un manejador:

Función del ejemplo

obtenerTriple(numero)

Calcula el triple de un número.

Parámetros: numero: número que se quiere triplicar.

Devuelve: El producto de numero por 3.

const obtenerTriple = function (numero) {
    return numero * 3;
};

console.log(obtenerTriple(4)); // 12

Aquí se crea una expresión de función y se asigna a obtenerTriple. const impide reasignar ese nombre, pero permite invocar la función tantas veces como sea necesario.

Una declaración como function mostrarInicio() { ... } puede invocarse antes de su posición en el código dentro de su ámbito. En cambio, una función asignada a const solo puede utilizarse después de inicializar la variable. En los ejemplos se definirán antes de llamarlas.

Guardar una referencia y pasar callbacks

const otra = obtenerTriple; guarda una referencia a la misma función; const valor = obtenerTriple(4); guarda su resultado. Una callback es una función recibida como argumento que otra función invoca cuando corresponde:

function aplicarTransformacion(numero, transformar) {
    return transformar(numero);
}

const resultadoTriple = aplicarTransformacion(5, obtenerTriple);
console.log(resultadoTriple); // 15

console.log(aplicarTransformacion(5, function (valor) {
    return valor + 10;
})); // 15

Las callbacks pueden ejecutarse inmediatamente, como aquí, o más tarde, como en los eventos. El punto y coma de const f = function () {}; termina la declaración de la variable.

Creación y ámbito

En modo estricto, una declaración de función dentro de un bloque está disponible únicamente en ese bloque. Para elegir una función condicionalmente y usarla después, declara una variable con let en el ámbito exterior y asígnale una expresión de función en cada rama.

9.6. Funciones flecha

Una función flecha es otra forma de escribir una expresión de función. Utiliza => entre los parámetros y el cuerpo:

const obtenerDoble = (numero) => {
    return numero * 2;
};

console.log(obtenerDoble(7)); // 14

Si el cuerpo es una única expresión, pueden omitirse las llaves y return. El resultado se devuelve de forma implícita:

Función del ejemplo

sumar(a, b) y crearAviso()

La primera suma dos números; la segunda construye un aviso fijo.

Parámetros: sumar recibe a y b, ambos números; crearAviso no recibe parámetros.

Devuelve: sumar devuelve la suma; crearAviso devuelve la cadena "Operación completada".

const obtenerDoble = (numero) => numero * 2;
const sumar = (a, b) => a + b;
const crearAviso = () => "Operación completada";

console.log(obtenerDoble(7)); // 14
console.log(sumar(3, 5));    // 8
console.log(crearAviso());   // Operación completada

Sin parámetros se escribe (). Con un único parámetro sencillo, los paréntesis son opcionales; en esta unidad se mantendrán por coherencia. Con varios parámetros son necesarios.

Llaves y retorno. (numero) => numero * 2 devuelve el resultado, pero (numero) => { numero * 2; } devuelve undefined. Con un cuerpo entre llaves debes escribir return si quieres devolver un valor.

Las funciones flecha no son intercambiables con function en todos los casos: no tienen su propio this y no se utilizan como constructores. Estos conceptos se estudiarán con los objetos. En los manejadores de esta unidad se utilizará event.currentTarget para acceder al elemento.

Apoyo: cadenas y arrays para los juegos

Un array guarda una secuencia de valores, por ejemplo const colores = ["rojo", "azul"];. Los índices empiezan en cero: colores[0] obtiene el primero. Puedes modificar una posición con colores[0] = "verde"; y consultar el número de elementos con colores.length. Recorre los índices con un for.

Para descubrir todas las apariciones de una letra, recorre la palabra. Las cadenas no permiten cambiar una posición directamente; un array sí.   3. Operar: ejecuta la operación seleccionada respetando el orden de los operandos. En una división, el segundo número es el divisor.
  4. Gestionar errores: no permitas dividir entre cero. Una operación desconocida o un resultado no finito también deben producir un mensaje de error.
  5. Mostrar: presenta el resultado con textContent y un mensaje de éxito. Ante un error, sustituye cualquier resultado anterior por — y muestra una explicación concreta.
  6. Limpiar: vacía los campos, selecciona de nuevo «Sumar», restaura — y elimina el mensaje y las clases de estado. Devuelve el foco al primer campo.

Validación desde JavaScript. El formulario utiliza novalidate para que programes las comprobaciones. El tipo number sigue condicionando la entrada: el navegador puede impedir escribir letras o representar una entrada no válida como una cadena vacía. No confundas un campo vacío con el número cero.

Al mostrar un error, añade error a #mensaje y retira exito; al mostrar un éxito, realiza lo contrario. Conserva la clase base mensaje.
