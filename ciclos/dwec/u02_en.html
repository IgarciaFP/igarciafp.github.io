1. Introduction to JavaScript

JavaScript (JS) is a programming language that allows processing data and giving behavior to a web page. With it you can perform calculations, check data from a form and update the content in response to the actions of the user.

In this unit you will work with JavaScript in the browserThe concepts will be practiced through short examples and independent activities.

1.1. Origin and evolution

JavaScript was created by Brendan Eich in 1995, during his work on Netscape. His initial purpose was to incorporate small interactions into the pages and execute instructions in the user's browser.

The appearance of different implementations required a common standard. These milestones summarize their evolution; the characteristics mentioned will be developed throughout the module.

  1. 1995 · Birth in Netscape

    Brendan Eich creates the language to incorporate interaction into web pages. Initially it is called Mocha, then LiveScript and finally JavaScript.

  2. 1997 · First ECMASScript standard

    Ecma International publishes ECMA-262 to establish common rules between implementations.

  3. 1999 · ECMASScript 3

    It incorporates regular expressions and exception handling. It becomes the base of JavaScript during the following decade.

  4. 2009 · ECMASScript 5

    Add strict mode, native JSON support and new methods to work with arrays.

  5. 2015 · ECMASScript 2015 (ES6)

    An important renewal: let, const, arrow functions, chain templates, classes, modules and promises.

  6. 2017 · Asynchronous functions

    async y await They will be studied in later units.

  7. 2020 · New Language Resources

    Optional chaining is incorporated (?.), the null coalescence operator (??) and BigInt.

ECMASScript is the specification that defines the language rules: your syntax, your data types and your operations. It is published as the standard ECMA-262 Ecma International and evolves through the work of the TC39 committee. JavaScript engines implement these rules.

1.3. Language characteristics

  • Dynamic typing. A fixed rate is not declared for each variable. Values have a type, and a variable can contain values of different types during execution. This does not eliminate the rules on which transactions each value supports.
  • Multiparadigm. It allows you to organize a program using instructions, functions and objects. In this unit instructions and functions will be used mainly.
  • I work with objects. The objects group data and related operations. In the browser they are used to represent, among other elements, the document and its controls. Their model is based on prototypes, which will be studied later.
  • Execution in different environments. In addition to browsers, there are environments like Node.js. The language is the same, but the tools available depend on the environment.

On the web pages it is common event-directed programming: sets which instructions to execute when something happens, such as pressing a button or modifying a field. The function that responds to that event is called event handler.

2.5. Loading and executing scripts

The browser processes HTML progressively. If a script is executed before the item you need exists, you will not be able to find it. Therefore, it is necessary to choose when the script should be executed.

The main loading options are:

  • Classic script without attributes: stops HTML analysis to load and execute the code.
  • defer: downloads an external classic script while continuing the analysis and executes it when HTML is already processed. Keeps the order between deferred scripts.
  • async: download in parallel and run when available. It does not guarantee that HTML is finished or the order between scripts.
  • type="module": load code as a module and it differs its execution by default. The modules will be developed in another unit.

In this practice it will be used <script src="ej02-javascriptExterno.js" defer></script>. defer has no effect on classic scripts written inside HTML and does not imply waiting for all images to be downloaded.

3.1. Values, expressions, instructions and blocks

A value is a data that the program works with, like the number 12the text "Hola" or the logical value true. When written directly into the code a literal.

One expression is a construction that is evaluated and produces a value. 8 + 4 produces 12. A literal can also constitute an expression.

In this example, 8 + 4 is the expression that calculates the result. The whole line is a instruction who calls console.log() to show it. An instruction represents a step of the program.

A block group instructions between keys. In this example the two instructions are executed in order:

Blocks will be used later in control structures and functions. Keys define the block; bleeding allows visual recognition of its contents.

5.3. Logical operators and null coalescence

When working with booleans, these operators allow to express composite conditions:

  • && (Y): the result is true if both conditions are true.
  • || (O): the result is true if at least one condition is true.

&& y || they evaluate from left to right and can omit the second operand if the first determines the result. short-circuit evaluation. With other data types return one of their operands, not necessarily a boolean. When checking them as a condition, values like false, 0, "", null, undefined y NaN are considered false; they are called falsy. The others are considered true (trusty). || returns the first operand if it is true and, if not, evaluates and returns the second; && returns the first if it is falsey and, if not, evaluates and returns the second.

Non-coalescence: ??

valor ?? alternativa returns the alternative only when valor is null o undefined. Allows to give a default value when a data is missing, retaining valid values as 0, false or an empty string. Do not modify the variable and only evaluate the alternative if you need it:

console.log(null ?? "Sin dato");     // "Sin dato"
console.log(0 ?? 10);                // 0
console.log(false ?? true);          // false
console.log("" ?? "Sin texto");      // ""
console.log(0 || 10);                // 10: || también sustituye los valores falsy.

?? y || are not equivalent. If zero means ‘no unit’, unidades ?? 1 retains that zero; unidades || 1 Choose according to which values you consider absent.
