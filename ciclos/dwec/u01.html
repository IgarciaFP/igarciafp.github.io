1. Tecnología Web

1.1. La World Wide Web

A menudo se confunde Internet con la Web, pero esta no existía desde el principio de Internet. Otros servicios como el correo electrónico, IRC, telnet, FTP, etc llegaron mucho antes.

En 1989, Tim Berners-Lee trabajaba en el CERN. Los científicos necesitaban compartir documentos entre ordenadores distintos...

1.3. Arquitectura cliente-servidor

La arquitectura cliente-servidor divide una aplicación en dos partes:

  • Cliente / frontend: interfaz que usa la persona, por ejemplo, una web o app.
  • Servidor / backend: recibe esas solicitudes, aplica la lógica del sistema y consulta bases de datos.
