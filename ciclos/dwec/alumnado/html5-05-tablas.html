Sección 05 · Comparar sin perder el significado

Datos con relaciones

Una tabla no es una cuadrícula decorativa: es una red de relaciones entre encabezados y datos. Cuando la estructura HTML es precisa, una persona puede comparar la información aunque no vea sus bordes.

Hoy: relacionar y verificar
01

Primero decide si realmente hay una tabla

<table> representa datos en dos dimensiones. Si cada valor necesita cruzarse con un encabezado de fila o columna para entenderse, probablemente es una tabla.

Sí es una tabla

Hay datos que se comparan

Horarios, resultados, inventarios o mediciones tienen categorías estables en filas y columnas. Cambiar el orden visual no elimina esas relaciones.

No es una tabla

Solo quieres colocar elementos

Una cabecera, una galería o dos columnas de una interfaz se organizan con CSS. Usar celdas para maquetar inventa relaciones que no existen.

Prueba de intercambio: si puedes formular preguntas como «¿qué valor corresponde a esta fila y esta columna?», los datos son tabulares. Si solo buscas una posición visual, no lo son.

02

La gramática de una tabla

La tabla tiene título propio, grupos de filas y dos tipos de celda. Cada etiqueta explica una parte de la estructura; ninguna se elige por negrita o por bordes.

<table>
  <caption>Sesiones de observación de octubre</caption>
  <thead>
    <tr>
      <th scope="col">Zona</th>
      <th scope="col">Fecha</th>
      <th scope="col">Objetos</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <th scope="row">Norte</th>
      <td><time datetime="2026-10-14">14/10</time></td>
      <td><data value="7">7</data></td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row">Resumen</th>
      <td colspan="2">Una sesión registrada</td>
    </tr>
  </tfoot>
</table>
table + caption

La tabla delimita el conjunto de datos y el título identifica con precisión qué se compara.

thead, tbody, tfoot

Agrupan cabecera, datos principales y resumen. No sustituyen a las filas.

tr

Crea una fila. Sus celdas deben formar una cuadrícula coherente con las demás filas.

th

Es un encabezado que nombra un conjunto de datos. Su función no es «poner texto en negrita».

td

Contiene un dato asociado a encabezados. No debe usarse cuando la celda nombra una fila o columna.

colspan y rowspan

Hacen que una celda ocupe varias columnas o filas; cambian la geometría y deben usarse con cálculo.

03

Una celda debe saber quién la explica

scope declara si un th encabeza una columna o una fila. Esa relación permite recorrer los datos sin depender de su posición visual.

Tabla sencilla: usa scope

  • ↓scope="col"El encabezado describe las celdas situadas debajo en esa columna.
  • →scope="row"El encabezado describe las celdas situadas a su derecha en esa fila.
  • ≠th no equivale a estiloSi algo no encabeza datos, no es th, aunque visualmente deba destacarse.
Tabla complejaAsociación explícita
<th id="meteo" colspan="2">Meteorología</th>
...
<th id="cielo" headers="meteo">Cielo</th>
<th id="viento" headers="meteo">Viento</th>
...
<td headers="zona-norte meteo cielo">
  Despejado
</td>

Complejidad con coste: cuando hay encabezados irregulares o de varios niveles, id y headers pueden declarar cada asociación. Antes de hacerlo, comprueba si dos tablas más sencillas comunicarían mejor la información.

04

Texto visible y valor procesable

Una persona puede preferir «14 de octubre» o «7 objetos», mientras que el navegador necesita formatos inequívocos. time y data permiten conservar ambas versiones.

Qué aporta cada elemento semántico dentro de una celda
ElementoTexto para la personaValor para software
time14 de octubredatetime="2026-10-14"
data7 objetosvalue="7"
Texto normalCielo despejadoNo necesita otra representación
<time datetime>

Fechas y horas en un formato válido y sin ambigüedad, aunque el texto visible esté localizado.

<data value>

Relaciona una expresión visible con un valor que puede procesarse, clasificarse o identificarse.

CSS, no atributos antiguos

border, cellpadding, cellspacing, align y bgcolor son presentación obsoleta.

Ejercicio práctico 05 · Proyecto acumulativo

Publica un registro de observaciones que pueda interpretarse

Carga tu index.html de la sección 04. Añadirás una única tabla con datos propios sobre las sesiones, eventos o recursos de tu proyecto, sin eliminar su estructura, navegación ni contenido multimedia.

70–90minutos

Contrato funcional

  • Conserva la estructura, la navegación, el botón, la figura, el vídeo y el audio de la sección 04.
  • Añade una tabla de datos con un caption descriptivo.
  • Escribe cuatro encabezados de columna y al menos tres filas de datos.
  • Cada fila tendrá un encabezado propio y tres celdas de datos.
  • Agrupa explícitamente la tabla con thead, tbody y tfoot.
  • Cierra con una fila de resumen que use un colspan coherente.

Criterios profesionales

  1. Usa scope="col" y scope="row" para declarar las relaciones.
  2. Incluye en cada fila una fecha mediante time datetime y una medida mediante data value.
  3. No dejes celdas vacías: escribe «No disponible» si ese dato tiene significado.
  4. No anides tablas ni uses una tabla para maquetar.
  5. No emplees atributos visuales obsoletos; el aspecto se resolverá más adelante con CSS.
  6. Redacta tus datos: los ejemplos se pueden consultar, pero no copiar desde esta ficha.

La comprobación analiza estructura y relaciones, no un texto concreto. Puedes adaptar las categorías al tema de tu proyecto.
