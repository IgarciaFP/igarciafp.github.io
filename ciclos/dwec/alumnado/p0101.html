10 misiones con Chrome DevTools

Aprende a mirar por dentro una página web, cambiarla de forma temporal y encontrar pistas. Cada misión dura entre 2 y 4 minutos.

⏱️ 35 min en total 🧩 Pasos cortos ✅ Comprobación inmediata 🔄 Nada se rompe
0 de 10 misiones

Antes de empezar

  1. Abre en Chrome el archivo dtcrashcourse.html del autor, mejor con un servidor local como Live Server.
  2. Ten esta guía en otra pestaña o ventana.
  3. Trabaja solo en la copia local de clase. No escribas nombres reales, correos ni contraseñas.
  4. Si algo queda raro, recarga con Ctrl + R. Los cambios de Elements desaparecen.

Regla de oro: DevTools sirve para investigar y probar. No lo uses para engañar, molestar o tocar páginas ajenas.

El mapa secreto

01

Abre la caja de herramientas

⏱ 2 min

Meta: abrir y cerrar DevTools sin perder la página.

  1. Haz clic derecho en cualquier parte de la página del proyecto.
  2. Elige Inspeccionar. Aparecerá DevTools a un lado o debajo.
  3. Ciérralo con la × y ábrelo otra vez con F12 o Ctrl + Mayús + I.

Lo lograste si… ves pestañas como Elements y Console.

💡 Si no sale

En Mac usa ⌘ + ⌥ + I. En algunos teclados, F12 necesita también Fn.

02

La lupa que encuentra etiquetas

⏱ 3 min

Meta: conectar una parte visible con su etiqueta HTML.

  1. Abre DevTools y entra en Elements.
  2. Pulsa el icono de flecha dentro de un cuadrado, arriba a la izquierda. Atajo: Ctrl + Mayús + C.
  3. Mueve el ratón sobre el título Hello World y haz clic.
  4. Busca en el código la etiqueta <h1>.

Lo lograste si… el título queda coloreado en la página y su línea está marcada en DevTools.

🧠 ¿Qué descubriste?

HTML es el esqueleto de la página. h1 significa “título principal”.

03

Cambia el titular… sin guardar

⏱ 3 min

Meta: editar el DOM y comprobar que el cambio es temporal.

  1. En Elements, haz doble clic sobre el texto Hello World.
  2. Escribe ¡Hola, detectives web! y pulsa Enter.
  3. Recarga con Ctrl + R.

Lo lograste si… primero aparece tu frase y, al recargar, vuelve Hello World.

🔎 Explicación corta

DevTools cambió la copia que Chrome tenía en memoria. No cambió el archivo original.

04

Pinta el título con CSS

⏱ 4 min

Meta: probar estilos sin editar el archivo.

  1. Selecciona otra vez el <h1> en Elements.
  2. En el panel Styles, haz clic dentro de element.style { }.
  3. Escribe color, pulsa Enter, escribe royalblue y pulsa Enter.
  4. Añade también background-color: gold.

Lo lograste si… ves letras azules sobre un fondo dorado.

🎨 Reto extra de 30 segundos

Haz clic en el cuadradito de color y elige otro. Después desmarca la casilla junto a una propiedad para apagarla.

05

Explora la caja invisible

⏱ 4 min

Meta: distinguir contenido, relleno y margen.

  1. Con el <h1> seleccionado, baja en el panel derecho hasta el dibujo Box model.
  2. Señala con el ratón cada anillo: content, padding, border y margin.
  3. Vuelve a Styles y añade padding: 20px.
  4. Cambia después a padding: 5px y compara.

Lo lograste si… el espacio alrededor del texto crece y encoge.

06

Habla con la Console

⏱ 3 min

Meta: ejecutar una instrucción sencilla y reconocer tres tipos de mensaje.

  1. Abre la pestaña Console.
  2. Escribe cada línea y pulsa Enter después de cada una:
console.log('Hola, clase'); console.warn('Atención: esto es una prueba'); console.error('Error de mentira');

Lo lograste si… aparecen un mensaje normal, una advertencia amarilla y un error rojo.

💡 Si Chrome no deja pegar

Escribe las líneas a mano. No actives permisos de pegado que no entiendas: la consola puede ejecutar instrucciones.

07

Convierte datos en una tabla

⏱ 3 min

Meta: mostrar información de forma ordenada con una línea del código del autor.

  1. En Console, escribe exactamente esta instrucción:
console.table([{name:'Ada', age:10}, {name:'Leo', age:11}]);
  1. Pulsa Enter y abre las filas si aparece una flechita.
  2. Limpia la consola con console.clear().

Lo lograste si… ves dos filas, una para Ada y otra para Leo, con columnas de nombre y edad.

🧠 ¿Qué significan los signos?

Los corchetes [ ] forman una lista y las llaves { } guardan datos de una persona inventada.

08

Encuentra una línea en Sources

⏱ 4 min

Meta: localizar código sin leer el archivo entero.

  1. Abre Sources. En la columna izquierda, busca y abre dtcrashcourse.html.
  2. Pulsa Ctrl + F y busca console.table.
  3. Después busca localStorage.
  4. Lee el número de línea que aparece a la izquierda de cada resultado.

Lo lograste si… encuentras ambas palabras y puedes señalar sus números de línea.

💡 Si no ves el archivo

Recarga la página con DevTools abierto. También puedes pulsar Ctrl + P y escribir parte del nombre del archivo.

09

Observa los viajes de la página

⏱ 4 min

Meta: ver qué archivos pide Chrome para construir la página.

  1. Abre Network y pulsa el icono de limpiar ⊘.
  2. Recarga la página. Verás aparecer varias filas.
  3. Haz clic en la fila de dtcrashcourse.html o en la primera fila de tipo document.
  4. Busca en Headers el valor Status Code. Normalmente será 200.

Lo lograste si… puedes explicar: “Chrome pidió un archivo y recibió una respuesta”.

🚦 ¿Qué significa 200?

Es el código que dice “todo ha ido bien”. Si trabajas con file:// quizá veas menos datos; usa el servidor local indicado al principio.

10

Abre las taquillas de datos

⏱ 4 min

Meta: distinguir datos locales, de sesión y cookies.

  1. Abre Application (quizá esté dentro de »).
  2. En Storage, abre Local Storage y el origen de tu página. Busca name → John.
  3. Abre Session Storage. Busca user → Will.
  4. Abre Cookies. Si el servidor local admite cookies, busca username → John Doe.

Lo lograste si… encuentras al menos dos de los tres pares de clave y valor.

💡 Si las taquillas están vacías

Ve a Console, ejecuta estas dos líneas y vuelve a Application:

localStorage.setItem('name','John'); sessionStorage.setItem('user','Will');

Guía rápida para el profesorado

Las tareas siguen el recorrido del vídeo, pero evitan técnicas avanzadas y acciones con riesgo. Pueden hacerse en dos sesiones: misiones 1–5 y 6–10.

NivelEvidencia observable
En procesoAbre DevTools con ayuda y reconoce al menos un panel.
ConseguidoCompleta 7 misiones y explica que los cambios de Elements son temporales.
AvanzadoCompleta 9–10 misiones y diferencia HTML, CSS, Console, Network y almacenamiento.
⭐ Ampliación opcional: Lighthouse (3–5 min extra)

El antiguo panel Audits del vídeo se llama ahora Lighthouse. Ábrelo, marca solo Accessibility, ejecuta el análisis y localiza una recomendación. El tiempo puede variar según el equipo, por eso no forma parte de las diez misiones.
