01

Abre DevTools

⏱ 2 min

Abre la caja de herramientas del navegador.

  1. Haz clic derecho sobre Planeta Web.
  2. Elige Inspeccionar.
  3. Ciérralo y vuelve a abrirlo con F12 o Ctrl + Mayús + I.

Comprobación: ves las pestañas Elements y Console.

02

Selecciona un elemento

⏱ 3 min

Relaciona lo que ves con su etiqueta HTML.

  1. Pulsa el selector de elementos, arriba a la izquierda de DevTools.
  2. Haz clic sobre el título Planeta Web.
  3. Localiza <h2 id="titulo-demo"> en Elements.

Comprobación: el título queda marcado en la página y en el código.

03

Cambia el título

⏱ 3 min

Edita el HTML de forma temporal.

  1. En Elements, haz doble clic sobre el texto Planeta Web.
  2. Escribe Estación DevTools y pulsa Enter.
  3. Recarga con Ctrl + R.

Comprobación: tras recargar vuelve a aparecer Planeta Web.

04

Cambia los colores

⏱ 4 min

Prueba CSS sin modificar el archivo.

  1. Selecciona #titulo-demo.
  2. En Styles, añade color: crimson.
  3. Añade background-color: gold.
  4. Desmarca y vuelve a marcar una propiedad.

Comprobación: el título tiene letras rojas y fondo dorado.

05

Agranda una caja

⏱ 4 min

Descubre el relleno de una tarjeta.

  1. Selecciona la tarjeta de Nova.
  2. En Styles, cambia padding: 1rem por padding: 30px.
  3. Baja hasta Box model y señala content, padding, border y margin.

Comprobación: Nova ocupa más espacio que Pixel y Byte.

💡 Idea clave

Padding es el espacio entre el contenido y el borde.

06

Activa una clase secreta

⏱ 4 min

Añade una clase CSS desde Elements.

  1. Selecciona la tarjeta de Pixel.
  2. Haz doble clic dentro de class="demo-card".
  3. Déjalo así: class="demo-card destacada".
  4. Pulsa Enter.

Comprobación: Pixel sube un poco y recibe borde dorado.

07

Da una orden en Console

⏱ 4 min

Usa JavaScript para cambiar un elemento.

  1. Abre Console.
  2. Escribe esta línea y pulsa Enter:
document.querySelector('#mensaje-demo').textContent = '¡Mensaje enviado desde Console!';
  1. Escribe console.log('Misión 7 lista').

Comprobación: cambia el mensaje y aparece una línea en la consola.

⚠️ Si Chrome no deja pegar

Escribe la instrucción a mano. Nunca pegues en Console código que no comprendas.

08

Encuentra una función

⏱ 4 min

Busca código dentro de Sources.

  1. Abre Sources y localiza este archivo HTML.
  2. Pulsa Ctrl + F.
  3. Busca sumarPunto.
  4. Lee las líneas siguientes y pulsa el botón azul de la zona de prácticas.

Comprobación: puedes explicar que la función aumenta el contador.

09

Mira cómo llega el HTML

⏱ 4 min

Observa la carga de la propia página.

  1. Abre Network y recarga.
  2. Selecciona la fila de tipo document, normalmente la primera.
  3. En Headers, busca Status Code.

Comprobación: ves 200 o puedes decir que Chrome ha cargado este HTML.

💡 Si abriste el archivo con file://

Puede que no aparezca el código 200. La fila del documento sigue siendo suficiente para completar la misión.

10

Abre las taquillas de datos

⏱ 4 min

Encuentra información guardada por esta página.

  1. Abre Application; puede estar dentro de ».
  2. En Local Storage, busca explorador → Ada.
  3. En Session Storage, busca equipo → Azul.

Comprobación: encuentras las dos parejas de clave y valor.

💡 Si no aparecen

Recarga la página y vuelve a mirar. Algunos navegadores limitan el almacenamiento en archivos locales.

🔥 RETO DIFÍCIL · 10 MINUTOS

Rescate en Planeta Web

Situación: la estación ha perdido su título, su tarjeta especial y su insignia. Debes repararla usando al menos cuatro paneles de DevTools. Esta vez no hay instrucciones paso a paso.

Objetivos

  1. Cambia el título visible a Misión completada.
  2. Haz que la tarjeta de Byte use la clase destacada.
  3. Desde Console, consigue que el contador muestre exactamente 25 puntos.
  4. Encuentra en Sources la función que actualiza el contador y di qué variable cambia.
  5. En Application, crea insignia → detective-web dentro de Local Storage.
  6. En Network, identifica el documento HTML cargado.

Condiciones

  • No edites el archivo con un editor.
  • No recargues hasta que el profesor compruebe el resultado.
  • Debes explicar qué panel usaste para cada cambio.
🧩 Pista 1

El título y la clase se pueden modificar desde Elements.

🧩 Pista 2

El contador tiene el identificador contador-demo. Necesitarás cambiar su textContent.

🧩 Pista 3

Para guardar la insignia: localStorage.setItem(clave, valor). Sustituye clave y valor por textos entre comillas.

✅ Solución técnicadocument.querySelector('#contador-demo').textContent = '25 puntos'; localStorage.setItem('insignia', 'detective-web');

En Sources, la variable que cambia es puntos.

Superado si… completas al menos 5 de los 6 objetivos y puedes explicar tus decisiones.

Para el profesorado

Propuesta de uso: misiones 1–5 en una sesión, misiones 6–10 en otra y el reto final como evaluación práctica. Para comprobar el reto, observe el título, la tarjeta Byte, el contador y la entrada de Local Storage; después pida al alumno que señale la función y la petición del documento.
