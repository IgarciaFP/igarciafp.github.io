Antes de la clase

El profesor debe proporcionar un repositorio de GitHub que contenga al menos un README.md. Una rama vacía no permite crear un Codespace.

Cuenta supervisada: el alumnado debe usar la cuenta y el repositorio indicados por el centro.

Reglas de seguridad

Nunca compartas contraseñas, tokens, claves ni datos personales.

Mantén el puerto 5173 privado. Para esta práctica no hay que hacerlo público. Detén el Codespace cuando termines para no consumir tiempo innecesario.

01

Crea el Codespace

⏱ 3–5 min

Abre un entorno de programación en la nube.

  1. Entra en el repositorio indicado por el profesor.
  2. Pulsa Code → Codespaces → Create codespace on main.
  3. Espera a que aparezca VS Code en el navegador.

Comprobación: el nombre del repositorio aparece en Explorer.

💡 Si no aparece el botón

Comprueba que has iniciado sesión, que tienes acceso al repositorio y que la rama contiene al menos un archivo.

02

Reconoce la interfaz

⏱ 4 min

Encuentra las partes principales de VS Code.

  1. Pulsa Explorer y abre README.md.
  2. Pulsa Search y busca una palabra del README.
  3. Abre la Command Palette y escribe theme; no cambies nada todavía.
  4. Abre y cierra el terminal con Ctrl + `.

Comprobación: puedes señalar Explorer, Editor, Terminal y Status Bar.

03

Crea package.json y .gitignore

⏱ 4 min

Define el proyecto y evita subir archivos pesados.

  1. En Explorer, pulsa New File y crea package.json.
  2. Copia este contenido y guarda con Ctrl + S.
package.json
{
  "name": "club-exploradores",
  "version": "1.0.0",
  "private": true,
  "type": "module",
  "scripts": {
    "dev": "vite --host 0.0.0.0"
  }
}
  1. Crea también .gitignore y escribe una sola línea:
node_modules/

Comprobación: package.json contiene el script dev y existe .gitignore.

🧠 ¿Para qué sirven?

package.json es la ficha del proyecto. .gitignore indica que Git no debe guardar la carpeta pesada node_modules.

04

Comprueba Node e instala Vite

⏱ 4–6 min

Usa el terminal integrado.

  1. Abre Terminal → New Terminal.
  2. Ejecuta estas órdenes de una en una:
node --version npm --version npm install -D vite

Comprobación: aparece node_modules, un package-lock.json y no termina con un error rojo.

💡 Si Vite avisa sobre Node

La versión actual de Vite requiere Node 20.19+ o 22.12+. Avisa al profesor para actualizar o reconstruir el Codespace.

05

Crea la web Club de Exploradores

⏱ 5 min

Crea un único archivo HTML con estructura, estilos e interacción.

  1. Crea index.html en la raíz del proyecto.
  2. Copia todo el código siguiente y guarda.
index.html
<!doctype html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Club de Exploradores</title>
  <style>
    :root { --principal: #2563eb; --fondo: #eff6ff; }
    * { box-sizing: border-box; }
    body {
      margin: 0; min-height: 100vh; display: grid; place-items: center;
      background: var(--fondo); color: #172033;
      font-family: system-ui, sans-serif;
    }
    main { width: min(900px, 92%); text-align: center; }
    h1 { margin-bottom: .3rem; color: var(--principal); font-size: 3rem; }
    .tarjetas {
      display: grid; grid-template-columns: repeat(3, 1fr);
      gap: 1rem; margin: 2rem 0;
    }
    article {
      padding: 1.2rem; border: 2px solid #bfdbfe;
      border-radius: 18px; background: white;
      box-shadow: 0 8px 20px #1e3a8a18;
    }
    .icono { font-size: 2.5rem; }
    button {
      border: 0; border-radius: 12px; padding: .8rem 1.2rem;
      color: white; background: var(--principal);
      font: inherit; font-weight: 800; cursor: pointer;
    }
    #mensaje { min-height: 1.6em; font-weight: 800; }
    @media (max-width: 650px) {
      .tarjetas { grid-template-columns: 1fr; }
      h1 { font-size: 2.2rem; }
    }
  </style>
</head>
<body>
  <main>
    <p>🚀 PROYECTO VITE</p>
    <h1>Club de Exploradores</h1>
    <p>Elige una misión y descubre el mundo de la programación.</p>

    <section class="tarjetas">
      <article><div class="icono">🌙</div><h2>Luna</h2><p>Observa el cielo.</p></article>
      <article><div class="icono">🌊</div><h2>Océano</h2><p>Investiga las mareas.</p></article>
      <article><div class="icono">🌿</div><h2>Bosque</h2><p>Protege la naturaleza.</p></article>
    </section>

    <button id="boton">Recibir una misión</button>
    <p id="mensaje" aria-live="polite"></p>
  </main>

  <script>
    const mensajes = [
      'Busca tres constelaciones.',
      'Descubre un animal marino.',
      'Dibuja la hoja de un árbol.'
    ];
    let turno = 0;
    document.querySelector('#boton').addEventListener('click', () => {
      document.querySelector('#mensaje').textContent = mensajes[turno];
      turno = (turno + 1) % mensajes.length;
    });
  </script>
</body>
</html>

Comprobación: Explorer muestra index.html, package.json y package-lock.json.

06

Practica edición y búsqueda

⏱ 4 min

Aprende tres herramientas básicas del editor.

  1. Pulsa Ctrl + F, busca Exploradores y cambia el título por Exploradores del Futuro.
  2. Abre la Command Palette, busca Format Document y ejecútalo.
  3. Haz clic en la línea del color #2563eb y prueba el selector de color. Guarda.

Comprobación: el archivo está ordenado y el nuevo título aparece dos veces: en <title> y en <h1>.

💡 Si solo cambiaste una aparición

Usa Ctrl + H para abrir Buscar y reemplazar.

07

Lanza Vite

⏱ 3 min

Inicia el servidor de desarrollo.

  1. En el terminal ejecuta:
npm run dev
  1. Espera a que aparezca una dirección con el puerto 5173.
  2. Pulsa Open in Browser en la notificación o abre el enlace del terminal.
  3. Si no se abre, entra en la pestaña PORTS y pulsa el icono del globo junto a 5173.

Comprobación: ves la web Club de Exploradores y el botón muestra misiones.

No cierres ese terminal: mientras Vite está funcionando, el terminal queda ocupado. Para detenerlo usa Ctrl + C.

08

Comprueba la recarga automática

⏱ 4 min

Observa cómo Vite actualiza la página al guardar.

  1. Deja la vista previa abierta en otra pestaña.
  2. En VS Code cambia 🚀 PROYECTO VITE por ✨ MI PRIMERA WEB.
  3. Guarda con Ctrl + S y vuelve a la vista previa.

Comprobación: el texto cambia sin ejecutar otra vez npm run dev.

🧠 ¿Qué ha ocurrido?

Vite detectó el archivo guardado y avisó al navegador para recargar la página.

09

Revisa y crea un commit

⏱ 5 min

Guarda una versión explicando qué contiene.

  1. Abre Source Control con el icono de la rama.
  2. Comprueba que node_modules no aparece gracias a .gitignore.
  3. Haz clic en index.html y revisa el comparador de cambios.
  4. Pulsa + junto a los archivos para prepararlos.
  5. Escribe el mensaje feat: crea web con Vite y pulsa Commit.

Comprobación: la lista de cambios queda vacía y aparece un commit saliente.

🧠 Tres palabras importantes
  • Stage: elegir lo que entrará.
  • Commit: crear una versión local.
  • Mensaje: explicar el cambio.
10

Sincroniza con GitHub

⏱ 3–5 min

Envía el commit al repositorio remoto.

  1. En Source Control pulsa Sync Changes o el icono de sincronización de la Status Bar.
  2. Si aparece una confirmación para obtener y enviar commits, acéptala.
  3. Vuelve a la página del repositorio en GitHub y recarga.
  4. Abre index.html y comprueba el mensaje del último commit.

Comprobación: GitHub muestra feat: crea web con Vite y los archivos del proyecto.

Importante: un commit no llega a GitHub hasta hacer push o Sync.

🔥 RETO FINAL · 10 MINUTOS

Amplía el Club de Exploradores

Misión: mejora el proyecto sin copiar una solución completa. Debes editar, comprobar en Vite y guardar una nueva versión en GitHub.

Objetivos

  1. Añade una cuarta tarjeta llamada Cometa con el icono ☄️.
  2. Cambia el color principal por otro que tenga suficiente contraste con el texto blanco del botón.
  3. Añade un pie de página con tu alias de clase.
  4. Comprueba que el botón sigue mostrando las tres misiones.
  5. Crea el commit feat: personaliza reto final.
  6. Sincroniza y verifica el commit en GitHub.

Condiciones

  • La vista móvil debe seguir mostrando una sola columna.
  • node_modules no puede aparecer en GitHub.
  • El terminal no debe mostrar errores.
🧩 Pista 1

Duplica uno de los bloques <article>...</article> y cambia su contenido.

🧩 Pista 2

Añade <footer>Creado por ALIAS</footer> antes de cerrar <main>.

🧩 Pista 3

El color principal está guardado en la variable CSS --principal.

Superado si… completas 5 de 6 objetivos y el último commit se ve en GitHub.
