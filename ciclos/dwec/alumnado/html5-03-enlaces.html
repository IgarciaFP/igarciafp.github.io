Hoy: conectar y orientar
01

Anatomía de un enlace

El elemento <a> necesita un destino en href y un texto que permita decidir si merece la pena seguirlo.

<a href="#equipo">Consultar el equipo necesario</a>
<a>…</a>

Delimita el contenido interactivo. Puede contener texto y otros elementos en contextos permitidos.

href

Indica la dirección del recurso o del fragmento. Un enlace sin destino no cumple su función.

Texto descriptivo

Debe tener sentido fuera de contexto. «Consultar el equipo necesario» informa mejor que «haz clic aquí».

02

Tres formas de expresar el destino

La forma de escribir href depende de si el destino está dentro del documento, dentro del proyecto o fuera del sitio.

TipoEjemploCuándo utilizarlo
Fragmentohref="#equipo"Desplaza hasta el elemento cuyo identificador es id="equipo".
Relativahref="index.html"Busca un archivo tomando como referencia la ubicación del documento actual.
Absolutahref="https://developer.mozilla.org/"Incluye protocolo y dominio para llegar a un recurso externo.
Misma página

Usa un fragmento

El valor que sigue a # debe coincidir exactamente con un id único.

Mismo proyecto

Usa una ruta relativa

Así el proyecto puede cambiar de dominio sin tener que reescribir todos sus enlaces.

Otro sitio

Usa una URL absoluta

Emplea https:// y describe la fuente o el recurso que encontrará el usuario.

03

Una navegación es un conjunto con propósito

<nav> identifica enlaces de navegación importantes. No debe envolver cualquier enlace aislado de la página.

Ejemplo de consultaNo copiar
<nav aria-label="Contenido">
  <ul>
    <li><a href="#equipo">Equipo</a></li>
    <li><a href="#proceso">Proceso</a></li>
    <li><a href="#fuentes">Fuentes</a></li>
  </ul>
</nav>

Contrato de una navegación fiable

  • ✓Destino existenteCada fragmento coincide con un identificador único.
  • ✓Texto comprensibleEl propósito se entiende sin recurrir a «aquí» o «clic».
  • ✓Estructura reconocibleLos enlaces relacionados se agrupan mediante una lista dentro de nav.
  • ✓Comportamiento seguroUna pestaña nueva exige informar y proteger la referencia de origen.

Si utilizas target="_blank": añade rel="noopener noreferrer". En general, abre otra pestaña solo cuando haya una razón clara.

04

Dónde abrir y qué elemento elegir

target decide el contexto de navegación. La elección entre <a> y <button> depende del propósito, nunca de la apariencia visual.

Valores habituales de targetContexto de navegación
ValorResultadoDecisión práctica
Sin atributo o _selfCarga el destino en el contexto actual.Es el comportamiento predeterminado y el más habitual.
_blankAbre normalmente una pestaña nueva.Úsalo con una razón clara, avisa en el texto y declara rel="noopener noreferrer".
_parentNavega el contexto padre.Tiene sentido dentro de un iframe; sin padre se comporta como _self.
_topNavega el contexto superior de la pestaña.Permite salir de varios niveles de marcos; sin antecesores se comporta como _self.
Nombre propioAbre o reutiliza un contexto con ese nombre.Por ejemplo, target="panel-ayuda"; evita crear pestañas nuevas en cada activación.

No confundas destino con seguridad

target indica dónde se muestra el recurso; rel describe la relación y puede limitar capacidades o información enviada.

Aunque los navegadores modernos protegen implícitamente muchos enlaces con _blank, en este proyecto se exige escribir noopener noreferrer para que la decisión sea explícita.

Nivel avanzado: el estándar también contempla _unfencedTop para marcos aislados especiales. No se utiliza en una navegación convencional.

Navegación

Usa <a href>

Cuando la activación lleva a otra URL, archivo, sección, correo o teléfono. El destino debe poder copiarse, abrirse en otra pestaña o guardarse.

<a href="recursos.html" target="_self">
  Consultar recursos
</a>
Acción

Usa <button>

Cuando la activación cambia la interfaz: mostrar contenido, abrir un diálogo, iniciar una reproducción o ejecutar una función. Escribe type="button": dentro de un formulario, omitir el tipo puede provocar un envío involuntario.

<button type="button">
  Activar modo nocturno
</button>
?Pregunta de decisión: «¿Voy a algún sitio?» → enlace. «¿Hago algo en esta interfaz?» → botón. CSS puede hacer que ambos se parezcan, pero no cambia su significado.

Ejercicio práctico 03 · Proyecto acumulativo

Construye una navegación y un control semánticamente correctos

Carga el index.html de la sección 02. Debes decidir identificadores, destinos, valores de target y cuándo corresponde un enlace o un botón; no hay una plantilla para copiar.

55–70minutos

Contrato funcional

  • Conserva el esqueleto, el contenido y la jerarquía anterior.
  • Marca el comienzo con id="inicio".
  • Crea una navegación con una lista, tres fragmentos y destinos únicos.
  • Añade una fuente HTTPS con target="_blank" y protección explícita.
  • Crea un enlace relativo a index.html con target="_self".
  • Incluye un regreso a #inicio y un botón de acción futura con type="button".

Criterios profesionales

  1. Planifica primero el mapa de destinos.
  2. Usa textos que expliquen qué encontrará la persona.
  3. No emplees href="#" ni protocolos javascript:.
  4. No coloques botones dentro de nav ni enlaces falsos para ejecutar acciones.
  5. El botón puede preparar una acción futura —por ejemplo, «Activar modo nocturno»— aunque todavía no tenga JavaScript.
  6. Prueba los destinos y depura las catorce comprobaciones.

El archivo se procesa localmente. No se envía a ningún servidor.
