Declaración

Activa el HTML moderno

<!doctype html> indica al navegador que debe interpretar el archivo según el estándar HTML actual.

ImportanteNo es una etiqueta HTML. Es una declaración y debe ocupar la primera línea del archivo.

Pista: las etiquetas de cierre llevan una barra, por ejemplo </body>.

Etiqueta

La marca entre signos < >, como <p> o </p>.

Elemento

La etiqueta de apertura, el contenido y el cierre forman juntos un elemento.

Atributo

Información adicional dentro de la apertura, como lang="es".

Regla 01

Abre y cierra

La mayoría de los elementos tienen una etiqueta inicial y otra final.

<p>Contenido</p>
Regla 02

Anida en orden

El último elemento que se abre debe ser el primero que se cierra.

<body><p>…</p></body> <body><p>…</body></p>
Regla 03

Usa sangría

Los espacios iniciales muestran visualmente qué elemento está dentro de otro.

<body> <h1>Título</h1> </body>

Ejercicio práctico 01 · Proyecto acumulativo

Construye la base de tu rincón digital

Elige un tema que te interese. Este archivo será el punto de partida del proyecto y lo ampliarás en las próximas secciones.

20–25minutos

Resultado esperado: una página que se abra en el navegador, tenga un nombre en la pestaña y muestre un título y una breve presentación.

  1. Elige el tema

    Puede ser música, deporte, videojuegos, naturaleza, tecnología o cualquier afición apropiada para clase.

  2. Crea el archivo

    Dentro de una carpeta nueva, crea un archivo llamado exactamente index.html.

  3. Escribe la estructura

    Usa la plantilla y sustituye cada texto marcado con CAMBIA ESTO.

  4. Comprueba el resultado

    Abre el archivo en un navegador y revisa tanto la pestaña como el contenido visible.

index.html · plantilla inicial 
<!doctype html>
<html lang="es">
<head>
  <meta charset="UTF-8">
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0">
  <title>CAMBIA ESTO: título de la pestaña</title>
</head>
<body>
  <h1>CAMBIA ESTO: nombre del proyecto</h1>
  <p>CAMBIA ESTO: presentación del tema</p>
</body>
</html>
