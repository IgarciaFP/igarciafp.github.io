Declaración

Activa el HTML moderno

<!doctype html> indica al navegador que debe interpretar el archivo según el estándar HTML actual.

ImportanteNo es una etiqueta HTML. Es una declaración y debe ocupar la primera línea del archivo.

Pista: las etiquetas de cierre llevan una barra, por ejemplo </body>.

Etiqueta

La marca entre signos < >, como <p> o </p>.

Elemento

La etiqueta de apertura, el contenido y el cierre forman juntos un elemento.

Atributo

Información adicional dentro de la apertura, como lang="es".

Regla 01

Abre y cierra

La mayoría de los elementos tienen una etiqueta inicial y otra final.

<p>Contenido</p>
Regla 02

Anida en orden

El último elemento que se abre debe ser el primero que se cierra.

<body><p>…</p></body> <body><p>…</body></p>
Regla 03

Usa sangría

Los espacios iniciales muestran visualmente qué elemento está dentro de otro.

<body> <h1>Título</h1> </body>

Ejercicio práctico 01 · Proyecto acumulativo

Construye la base de tu rincón digital

Elige un tema, escribe el documento completo sin pegar código y somételo a pruebas automáticas. Este archivo será la base de las siguientes secciones.

35–45minutos

Encargo: crea desde cero una página válida sobre un tema de tu elección. Puedes consultar el ejemplo anterior, pero debes reconstruir la estructura razonando qué elemento corresponde en cada lugar.

  1. Planifica el contenido

    Decide un título para la pestaña, un encabezado principal y una presentación precisa de entre 50 y 220 caracteres.

  2. Escribe sin copiar ni pegar

    Empieza por la declaración HTML5 y teclea después la estructura completa en el editor.

  3. Ejecuta las pruebas

    No te limites a la vista previa: el navegador puede corregir silenciosamente un documento mal escrito.

  4. Depura con las pistas

    Corrige el orden, el anidamiento, los metadatos y la sangría hasta superar las diez pruebas.

  5. Descarga y verifica

    Solo cuando obtengas 10/10 podrás descargar index.html y abrirlo fuera de esta ficha.

Contrato técnico

  • Declaración HTML5 en la primera línea.
  • Idioma español y codificación UTF-8.
  • Configuración correcta para dispositivos móviles.
  • <head> antes de <body>, con cierre y anidamiento correctos.
  • Un <title>, exactamente un <h1> y exactamente un <p>.
  • Sangría coherente de dos espacios por nivel.

Regla de aprendizaje: el editor bloquea el pegado y el arrastre de texto. Consultar el ejemplo está permitido; reproducirlo mecánicamente, no.
