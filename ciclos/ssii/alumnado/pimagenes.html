¿Cómo se forma un color en pantalla?

Mezcla luz roja, verde y azul y observa cómo se codifica.

RGB · 24 bits

Tres cantidades forman cada píxel

Una pantalla mezcla luz roja, verde y azul. Cada componente puede tomar 256 valores, desde 0 (apagado) hasta 255 (máxima intensidad).

R0–255 · 8 bits
G0–255 · 8 bits
B0–255 · 8 bits
Profundidad de color Con 8 bits por canal tenemos 24 bits: 256 × 256 × 256 = 16.777.216 colores posibles. Un cuarto canal, alfa, puede indicar transparencia.

BMP · mapa de bits

Archivo original

Un BMP describe una cuadrícula de píxeles. Este archivo conserva mucha información directa y por eso sirve como referencia de calidad, aunque ocupa bastante espacio.

Comprueba lo que has aprendido

Responde a partir de lo que has observado, no solo de memoria.

10 preguntas
1. ¿Cómo se representa normalmente el color de un píxel en pantalla?

RGB combina tres canales. Con 8 bits por canal cada uno admite 256 valores.

2. ¿Qué diferencia principal hay entre una imagen sin comprimir y una comprimida?

La compresión reduce el tamaño de archivo. Puede ser sin pérdida o con pérdida.

3. ¿Qué significa «compresión sin pérdida»?

PNG es un ejemplo habitual de compresión sin pérdida: reduce datos sin eliminar información visual.

4. ¿Qué distingue a un mapa de bits de una imagen vectorial?

La estructura interna importa: píxeles en una imagen rasterizada y formas/curvas en una vectorial.

5. ¿Qué suele ocurrir al ampliar mucho una imagen?

El vector se vuelve a dibujar a cualquier escala. El mapa de bits solo dispone de sus píxeles originales.

6. Si convertimos este BMP a un archivo llamado SVG, ¿se vuelve necesariamente vectorial?

Un contenedor SVG puede incluir imágenes rasterizadas. Para obtener vectores reales hay que trazar o reconstruir sus formas.

7. ¿Qué relación suele existir entre compresión con pérdida, tamaño y calidad?

Reducir datos tiene un coste cuando se usa compresión con pérdida: hay que buscar un equilibrio útil.

8. Para una fotografía o imagen compleja en una página web, ¿qué opción inicial suele ser razonable?

WebP suele comprimir bien fotografías e imágenes complejas para la web. La elección debe verificarse con el contenido real.

9. ¿Qué formato elegirías para un logotipo o icono que debe verse bien a cualquier tamaño?

Un SVG vectorial es adecuado para logotipos, iconos y diagramas escalables.

10. ¿Existe un único formato que sea siempre el mejor para una página web?

WebP/JPG suelen servir para fotografías, PNG para gráficos sin pérdida o transparencia, SVG para vectores y GIF para animaciones sencillas o compatibilidad concreta.
