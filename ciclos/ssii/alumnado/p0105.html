1. El binario como código intermedio

Decimal
base 10
⇄
Binario
base 2
⇄
Octal o hexadecimal
bases 8 y 16
Octal: grupos de 3 bitsPorque 2³ = 8. Cada grupo representa exactamente una cifra de 0 a 7.
Hexadecimal: grupos de 4 bitsPorque 2⁴ = 16. Cada grupo representa una cifra de 0 a F.

Regla de agrupación: separa los bits desde la derecha. Si el primer grupo queda incompleto, añade ceros solamente a la izquierda. Esos ceros no cambian el valor.

2. Conversión entre decimal y octal

Decimal → octal: convierte primero a binario y agrupa de 3 en 3. Octal → decimal: cambia cada cifra por sus 3 bits y convierte ese binario a decimal.

Decimal → octal · Ejemplo 1

45₁₀ → ?₈

  1. Decimal a binario: 45₁₀ = 101101₂.
  2. Agrupamos desde la derecha: 101 · 101.
  3. Cada grupo: 101₂ = 5 y 101₂ = 5.
45₁₀ = 101101₂ = 55₈

Decimal → octal · Ejemplo 2

156₁₀ → ?₈

  1. Decimal a binario: 156₁₀ = 10011100₂.
  2. Completamos y agrupamos: 010 · 011 · 100.
  3. 010₂ = 2, 011₂ = 3 y 100₂ = 4.
156₁₀ = 10011100₂ = 234₈

Octal → decimal · Ejemplo 1

73₈ → ?₁₀

  1. Cada cifra ocupa 3 bits: 7 → 111 y 3 → 011.
  2. Unimos: 73₈ = 111011₂.
  3. Binario a decimal: 32 + 16 + 8 + 2 + 1 = 59.
73₈ = 111011₂ = 59₁₀

Octal → decimal · Ejemplo 2

245₈ → ?₁₀

  1. 2 → 010, 4 → 100 y 5 → 101.
  2. Unimos: 010 · 100 · 101 = 10100101₂.
  3. Binario a decimal: 128 + 32 + 4 + 1 = 165.
245₈ = 10100101₂ = 165₁₀

3. Conversión entre decimal y hexadecimal

Decimal → hexadecimal: convierte a binario y agrupa de 4 en 4. Hexadecimal → decimal: sustituye cada cifra por sus 4 bits y pasa el binario a decimal.

Decimal → hexadecimal · Ejemplo 1

45₁₀ → ?₁₆

  1. Decimal a binario: 45₁₀ = 101101₂.
  2. Completamos y agrupamos: 0010 · 1101.
  3. 0010₂ = 2 y 1101₂ = 13, que se escribe D.
45₁₀ = 101101₂ = 2D₁₆

Decimal → hexadecimal · Ejemplo 2

156₁₀ → ?₁₆

  1. Decimal a binario: 156₁₀ = 10011100₂.
  2. Agrupamos: 1001 · 1100.
  3. 1001₂ = 9 y 1100₂ = 12, que se escribe C.
156₁₀ = 10011100₂ = 9C₁₆

Hexadecimal → decimal · Ejemplo 1

3A₁₆ → ?₁₀

  1. 3 → 0011 y A → 1010.
  2. Unimos: 0011 · 1010 = 111010₂.
  3. Binario a decimal: 32 + 16 + 8 + 2 = 58.
3A₁₆ = 111010₂ = 58₁₀

Hexadecimal → decimal · Ejemplo 2

B7₁₆ → ?₁₀

  1. B → 1011 y 7 → 0111.
  2. Unimos: 1011 · 0111 = 10110111₂.
  3. Binario a decimal: 128 + 32 + 16 + 4 + 2 + 1 = 183.
B7₁₆ = 10110111₂ = 183₁₀
