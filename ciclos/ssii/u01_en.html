1. Introduction and previous definitions

1.1. Hardware and Software

We understand by architecture of a computer the parts that compose it, so we can talk about two basic components in a computer:

► Physical componentsalso called as a whole hardware and consisting of all the circuitry and electronic components of the computer.

► Logical components, also called together software and which is made up of the intangible components of a computer; that is, the programs that run on the computer, as well as the information or data that are processed. A computer without software would make no sense, it would only be a machine that would do nothing.

Remember:

If we can touch it it is hardware (physical component), if it is intangible it is software (logical component).

1.2. Computers and Computers

The computer science is the science that studies the acquisition, representation, processing and transmission of information, automatically using machines called computers.

The term information In computer science it has a broad meaning, and refers to a set of symbols that represent facts, objects or ideas.

The computer is a machine, usually electronic and digital, capable of accepting input data, carrying out with them a series of mathematical and logical operations and providing the resulting information through an output medium; all without human intervention, using a set of instructions, that is, a program previously stored in the computer memory.

3.1. Computer units and magnitudes

3.1.1. Units of measurement for the storage of information

As we saw at the beginning of the topic, the bit is the smallest unit to measure any information, but just as we did not measure the distance between cities in centimeters, neither will we use the bit, but multiples of it, as a general rule.

In fact, the minimum amount of information that a computer is going to try will be 8 bitsThis is 1 Byte, and multiples of it using Greek prefixes: Kilo, Mega, Giga, Tera, Peta, Exa, Zetta, Yotta.

Traditionally (since the 1960s) the multiplication scale has always been expressed in power of 2 to 10 (1024), although attempts have been made to normalize the use of the 1000 scale by the IEC since 1998, introducing the Kibibyte, Mebibyte, etc. nomenclature for 2 powersIts use is still discussed today (year 2022) by the scientific community, so that some adopt the standard on base 10 (Ubuntu for example) and others on base 2 (Microsoft without going further). 3.1.2. Units of measurement for the transmission of information

Traditionally the sending of information in analogue media was carried out in baudios, which measures the number of changes in the signal per second, however currently the bit per second (bps or bit/s) which is a much more precise measure.

In order to name multiples of the bit/s, Kilobits/s, Megabits/s etc should usually be noted, however these measures expressed in bytes per second and also in Megatransfers.

A Megatransfer (Millions of transfers per second) is equivalent to the Megabit per second except for the fact that it measures all data being transferred including synchronization and error control information, which allows to use round units when giving information about the transfer rate of a communications bus.

3.1.3. Measurement units for image

The basic unit to measure an image is the pixel (picture element) or point of light, whose size, depth of color and distance to other points will depend entirely on the technology used and the precision that you want to give it. For your multiples the same prefixes are used as for the bit.

3.3.1 Numerical representation

A first approach to the problem of representing a designated number of n-bits is representation in Sign and Magnitude:

  • The MSB is used to represent the number that, per convention: a 0 denotes a positive number, and a 1 denotes a negative number;

  • The remaining (n-1)-bits to represent the meaning that is the magnitude of the number in absolute value.

One problem of this representation is the need for a conditional operation when operating with them to determine their sign and another the double representation of zero (1000000 and 0000000)

Much more used is representation in Pluginswhich allows us to have a simpler arithmetic.

  • Plugin to 1 (to the base minus 1): Zeros and ones of meaning are reversed - it is equivalent to subtracting the base minus 1- , which allows us to operate arithmetically, although transport must be taken into account and still has double representation for zero. It is used by TCP, UDP, ICMP protocols, and others. e.g.: 1010)2 = -5)10

  • Plugin to 2 (to the base): 1 is added to the complement to 1 of the number, which gives us a very effective notation to operate arithmetically. It is the most used notation. e.g.: 1011)2 = -5)10

To represent numbers real or very large the floating point notation, which is based on the property that every n number can be represented by n=m*Be where m is the mantisa, B is the base (it is not necessary to explain this value) and e is the exponent.

There is currently the standard IEEE 754 virtually universal acceptance, which represents real number with 32 or 64 bits.

3.3.4. Image and video representation

The encoding of static images can be done in ways: by means of bitmaps (indicating for each bit of the screen its color) or by vector representation (Indicating only the vertices and color of each polygon we want to generate).

Each pixel will be represented using an RGB color scale (Red, Green and Blue) or CMYK (Cyan, Magenta, Yellow, blacK -for printers-) thus reducing to three numbers (4 in the case of printing) that symbolize the amount of each color that will be mixed to generate the resulting color.

On-screen colours can be incorporated into a fourth value that represents the transparency of the image, and is known as the “Alpha channel”.

The resolution of an image is therefore determined by the number of points we are going to use to represent it, but also by the amount of colors that allows us the palette we are using, depending on the number of bits that we dedicate to each basic color. For example, if we use 8 bits for the palette, we can represent 2 bits.8 different combinations, i.e. 256 colors, but if we use 16 bits, 65536. The number of bits used is called “color depth”.

It is also common to compress images so that they are smaller by reducing the color depth, resolution of the image, or the number of pixels to be represented by the bit zone approach of the same colour.

A video is always going to be formed from static images, being important the number of images (frames) that are represented FPS and taking into account that compression can also be performed by transitions between images, that is, keeping the elements that do not change and saving information from those that do.

4. Features of a digital computer

There are a number of features or parameters that allow us to compare digital computers. We list in this section the relevant features of a digital computer.

4.1. Word length:

The length of the bit chain that the computer can handle simultaneously (in parallel). Thus a 32-bit computer can perform operations with operands of this size at once. Currently, 32 and 64bit computers are marketed

4.2. Main Report (RAM)

  • Main internal memory size of the computer. The basic unit is byte or octet (8 bits) although multiples are usually used

4.3. Secondary report

Amount of storage or permanent memory available to the computer (usually, hard drive capacity, gigabytes or terabytes)

4.4. Bandwidth

The bandwidth is the amount of information per unit of time that can be transmitted via a bus or I/O unit. It is measured in MB/s Mb/s or GT/s

4.5. Clock frequency

Frequency with which the internal oscillator (watch) coordinates the computer operations, usually measured in MHZ or GHZRemember: A Mhz is...

4.6. MIPS (Millions of Instructions per second)

Computer performance measure, which indicates the number of machine instructions a processor can run in a second, grouped into millions.

4.7. MFLOPS

Measure similar to the previous one, but exclusively for operations with actual floating point numbers, which present a higher calculation load.

4.8. Synthetic tests (Benchmarks)

They are a varied set of tests whose result at run time is more reliable than the measurement in MIPS, MFLOPS or GHZ. The result of these tests results in a ranking of power.

5. Physical Components. Von Neumann Architecture

5.1. Introduction: Von Neumann Architecture

The basic architecture model used in digital computers was established in 1945 by John Von NeumannHungarian physicist based in the United States.

His great contribution to pre-existing architectures (hardvard architecture mainly) was to eliminate the programming logic based on relays or wired connections, unifying data memory and program memory into a single main memory and thus simplifying the dual management of data control and programme. incremental space availability in memory as this can be divided between data and programs at will.

The functional elements of the Von Neumann architecture are therefore:

  • Control Unit

  • Arithmetic-logical unit

  • Main Memory

  • I/O unit

The control unit and the arithmetic-logical unit are grouped in the so-called Central processing unit.

5.2. Components. Functional CPU blocks

The Central Process Unit (CPU = Central Process Unit) unifies the functional elements of Control Unit and Arithmetic-Logic Unit.

5.2.1. Control Unit

It is the nerve center of the computer, where the programs are processed and its function is to perform the search, load, sequencing and execution of the instructions.

These instructions are written in Language Machine and are formed by a operation code, which indicates to UC which operation should be carried out, and up to two memory data or addresses which indicate the location of that data.

To perform its work, UC uses the following elements:

Records, some visible to the user and others do not, These include:

  • Programme counter(PC). Contains at all times the memory address of the following command to execute.

  • Instruction(IR) Record Stores the current instruction, which will carry with it the operating code and, where appropriate, the operands or memory addresses of the same.

  • Recording of memory addresses (MAR) They are used to store memory addresses containing the data of an instruction or the place where to store the result of it.

  • Memory Exchange Record(MIR): Any recovered memory information is stored temporarily.

  • Status records (Flags/PSW)It contains information on the outcome of the previous operation of the logical arithmetic unit and possible anomalous situations, such as overflows, interruptions, etc.

  • Other records, as the generic records which can be used by the programmes themselves and others specific records used by the processor (stack pointer, baseline logetc.) and that depend on their concrete architecture.

Clock. The clock is an oscillator circuit that autonomously generates a signal in the form of pulses at constant intervals that mark the moments in which the different steps of each instruction must begin.

Decoder. It is responsible for extracting the operating code from the current instruction, analyzing it and issuing the necessary signals to the other elements for execution through the sequencer.

Sequencer. It generates a series of very elementary commands that allow to execute the current instruction, in a synchronous way with the system clock.

Finally, it should be noted that the Control Units can be classified as two
categories:

  • UC wired. Logic is implemented in hardware, which makes it UC of specific purpose And it's not modifiable.

  • Microprogrammed UC. In them, logic is implemented as a stored program as firmwareWhich allows for his subsequent rewriting.

5.2.2. Arithmetic-Logic Unit

It is the functional unit responsible for performing arithmetic and logic operations. under the supervision of the control unit.

The operations that this unit can carry out They used to be very elementary.since they were normally composed of a summer-restoring circuit, and based all arithmetic operations on sums, decomposing complex operations into elementary steps.

Currently the Arithmetic Unit has taken on great importance and the type of operations it carries out is very complex, being similar to a scientific calculator of high speed and high precision.

The operations that ALU is capable of performing are classified into three groups:

  • Arithmetic. Usually are the sum (ADD), subtraction (SUB), multiplication (MUL), division (DIV) and change of sign.

  • Logic. Usually they are denial (NOT), logical sum (OR), logical product (AND) and exclusive sum (XOR).

  • Displacement. It consists of moving the bits of a word a certain number of positions to the right or to the left.

The number of operators that can accept the arithmetic-logical unit is also variable, classified as operators monodic, diadic and triadic if you are able to work with one, two or three data simultaneously respectively

5.3. Role and Purpose of Internal Memory

Memory is considered a single functional component, composed of cells that can store bits independently, with two basic operations: reading and writing.

However, the limitations in terms of performance, economic cost and speed make it necessary to structure it.

5.3.1. Memory hierarchy

The author Pedro de Miguel de Anasagastiin his book Fundamentals of Computers, he characterizes memory according to:

  • The cost per bit

  • Time taken to access information

  • Storage capacity or size

The desired values for a memory are a large storage capacity, a small access time, and a reduced price. However, this combination does not exist: A quick memory is a expensive memory. This limitation is valid from the time the first memories emerged to the present day. Fast memories, without refresh cycles, with almost non-existent latencies, require the use of expensive components: integrated bistables of high conductivity, whose manufacturing process is expensive and whose materials are expensive. more memory capacity, more economic cost.

Fortunately. not all memory needs to be accessed at a given time. This enables the instructions and data required by the processor can be hierarchized in different memories depending on the immediacy required for your process.

The hierarchy of memory then conforms to very fast, expensive and low capacity memories for data in process up to relatively slow, high capacity and low cost memories per bit for data that will not be processed in the near future (not in the next few seconds). The different memories from lower to higher capacity and higher at lower speed and cost are classified as:

  • Records (processor)

  • Memory cache (structured in levels: L1, L2, L3, etc.)

  • Main Memory (Dynamic RAM)

  • Secondary memory (hard disks and solid state)

  • Auxiliary mass memory (backing brackets)

Data must be transferred from memory to memory according to the required availability.

5.3.2. Functions by level

As we see in the hierarchy of memory, the internal memory is composed of 3 levels, each of which has the following specific functions:

  • Level 0 - Records: Stores data on which the control unit is working directly.

  • Level 1 - Cache: Memory formed by integrated circuits SRAM. In turn it is divided into several levels. It is used to minimize accesses to the main memory.

  • Level 2 - Main memory. Memory formed by DRAM, whose function is to store the instructions and data that are being used in the execution of a process.

5.4. I/O buses

The set of components of a computer communicates with each other through certain paths, which constitute the interconnection structure, or I/O buses.

In the architecture Von Neumann are distinguished the buses data, address and control:

5.4.1. Data Bus:

The data bus allows the exchange of data between the CPU and the rest of units.

5.4.2. Address bus:

RAM is addressable, so that each memory cell has its own address. Addresses are a number that selects a memory cell within the main memory or in the address space of the input/output unit.

The address bus is a channel of the microprocessor completely independent of the data bus where the memory address of the data in transit is established.

The steering bus consists of the set of electrical lines necessary to establish a direction. The memory capacity that can be directed depends on the amount of bits that make up the direction bus, being 2n the maximum bit size of the memory bank that can be addressed with n lines. For example, to address a 256 bit memory, at least 8 lines are necessary, as 28 = 256. In addition, control lines may be required to indicate when the address is available on the bus. This depends on the bus design itself.

5.4.3. Control bus:

The control bus governs the use and access of data and address lines. Since these lines are shared by all components, it has to be provided with certain mechanisms that control their use. Control signals transmit both commands and synchronization information, preventing a collision of information in the system.

5.4.4 Multiplexed buses:

Some designs use multiplexed electric lines for the address bus and data bus. This means that the same set of electrical lines behave a few times as a address bus and other times as a data bus, but never at the same time. A control line allows you to discern which of the two functions is active.

5.5. Peripherals

Peripherals are interconnected to the I/O unit by using a interface with access specifications standardized both at form level, voltage level and communication protocols.

Each peripheral has a control circuit (or controller) that manages all the logic of it.

The peculiarities of each device are managed transparently by the operating system by means of a driver software (driver) which is normally provided by the manufacturer himself.

Peripherals can be classified in devices such as Entry, of Output, or of entry and exit; the latter are of type storage o communication.
