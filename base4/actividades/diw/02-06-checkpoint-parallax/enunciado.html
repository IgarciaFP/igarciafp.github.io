Checkpoint 06 · Crea y comprueba un efecto parallax

Tiempo disponible: 105 minutos.

Objetivo: crear un efecto de profundidad decorativo que tenga una alternativa estable para quien prefiere menos movimiento.

El parallax crea sensación de profundidad cuando el fondo y el contenido se desplazan de forma distinta. Una aproximación sencilla consiste en fijar una imagen de fondo a la ventana mientras el texto se desplaza por encima.

<section class="parallax">
  <h2>Descubre nuestro entorno</h2>
</section>

.parallax {
  min-height: 20rem;
  padding: 3rem 1rem;
  color: white;
  background-image: linear-gradient(rgb(0 0 0 / .65), rgb(0 0 0 / .65)),
                    url("imagenes/paisaje.jpg");
  background-position: center;
  background-size: cover;
  background-repeat: no-repeat;
  background-attachment: scroll;
}

/* Activarlo en pantallas amplias, si no se pide reducir movimiento. */
@media (min-width: 48rem) and (prefers-reduced-motion: no-preference) {
  .parallax { background-attachment: fixed; }
}
  1. Construye la escena. Usa el ejemplo con una fotografía propia y añade contenido antes y después de la sección para poder desplazarte por la página. Ajusta la capa oscura hasta que el título se lea bien.
  2. Compara los dos fondos. En una ventana de al menos 48rem de ancho y con la preferencia de movimiento normal, alterna scroll y fixed en la regla de medios. Desplázate por el mismo tramo en ambas pruebas. Elige un detalle reconocible de la foto y describe cómo cambia su posición respecto al título.
  3. Comprueba la alternativa con menos movimiento. Deja fixed en la regla de medios y activa la preferencia de movimiento reducido del sistema. Repite la prueba y comprueba en el inspector qué valor de background-attachment se aplica ahora.

Se valorará: contraste suficiente del título, comparación descrita entre scroll y fixed y alternativa de movimiento reducido comprobada en el inspector.
