Validación de una edad

Se proporciona un formulario de entrada de edad en la pestaña HTML y sus estilos en CSS. Escribe en JavaScript el código que compruebe que el campo contiene un número entero entre 1 y 120, ambos incluidos. El campo vacío no es válido.

  1. Comprueba la edad al pulsar Aceptar o Intro. Debes controlar ambos casos.
  2. Aplica al campo la clase correcto si la edad es válida, o error en cualquier otro caso. Al cambiar el resultado, retira la clase anterior.
  3. Si el campo tiene la clase correcto, muestra «Edad válida» en el elemento de salida.
  4. Si tiene la clase error, muestra «Revisa la edad introducida».
  5. Cancela desde JavaScript el envío por defecto del formulario para que se pueda leer el mensaje. Debes hacerlo en tu código aunque el entorno protegido también impida navegar.
  6. Utiliza comentarios y buenas prácticas de programación. El trabajo que se evalúa es el JavaScript; utiliza el HTML y el CSS proporcionados.

Prueba tu código: pulsa Ejecutar y comprueba 18 con Intro y 121 con Aceptar. Repite con 1, 120, 0, -1, 18.5 y el campo vacío. Alterna valores válidos e inválidos para comprobar que cambian la clase y el mensaje. Usa Actualizar en Resultado para reiniciar el formulario.

Cuando termines, pulsa Entregar en la barra superior del laboratorio.
