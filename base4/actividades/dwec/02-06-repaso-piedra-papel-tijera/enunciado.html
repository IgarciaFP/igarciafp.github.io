Repaso · Piedra, papel o tijera

Programa en JavaScript una partida contra el ordenador. Al abrir el juego se ven tres botones: Piedra, Papel y Tijera. El HTML ya está preparado.

  1. Lee la jugada del usuario. Cada clic inicia una ronda. El atributo value del botón pulsado contiene la opción elegida en minúsculas.
  2. Genera la jugada del ordenador. Declara esta lista una vez: 
    const jugadas = ["piedra", "papel", "tijera"];
    Dentro del manejador del clic, utiliza esta fórmula para elegir de nuevo en cada ronda: 
    const jugadaOrdenador = jugadas[Math.floor(Math.random() * jugadas.length)];
    El índice aleatorio puede ser 0, 1 o 2. Las tres opciones tienen la misma probabilidad.
  3. Anuncia el resultado. Piedra vence a tijera, tijera vence a papel y papel vence a piedra. Dos jugadas iguales empatan. Muestra ambas elecciones en #resultado e indica quién gana o si hay empate. Por ejemplo: «Has elegido tijera. El ordenador ha elegido piedra. Gana el ordenador».
  4. Actualiza el marcador del usuario. Inicializa a cero tres contadores fuera del manejador. Después de anunciar el resultado, incrementa solo el que corresponda y muestra los tres totales en #marcador. Conserva las cuentas para el siguiente clic.

Comprueba tu juego. Para probarlo, fija temporalmente la jugada del ordenador en "piedra". Desde una partida nueva, pulsa Papel, Tijera y Piedra. Debes ver, por orden, una victoria, una derrota y un empate. El marcador final debe indicar «Victorias: 1 · Derrotas: 1 · Empates: 1». Recupera la fórmula aleatoria antes de entregar.

Condición de realización: utiliza los botones y elementos de la propia página para toda la interacción. No utilices prompt(), alert(), confirm(), métodos de console ni la instrucción debugger.

Tiempo: 60 minutos. Puedes utilizar Pausar y recuperar después el archivo desde el inicio del laboratorio.
