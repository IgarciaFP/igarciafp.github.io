Prueba tu habilidad en CSS

El HTML ya contiene una cabecera h1 con el texto «Prueba tu habilidad en CSS». Escribe el CSS necesario en la pestaña CSS, sin modificar el HTML ni utilizar JavaScript.

  1. Muestra el texto de la cabecera en blanco sobre un fondo negro.
  2. Utiliza variables CSS (propiedades personalizadas) para definir y aplicar el color del texto, el color de fondo y el tamaño de la letra.
  3. Haz que el tamaño del texto aumente de forma fluida cuando aumente el ancho de la página y disminuya cuando el ancho se reduzca. Un tamaño fijo no cumple este requisito.

Resultado esperado: la cabecera conserva el texto original, aparece en blanco sobre negro y su tamaño se adapta al ancho disponible. El resultado se actualiza mientras escribes CSS.

Entrega: comprueba los requisitos y pulsa Entregar.
